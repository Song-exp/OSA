# 환자 검수 이후 CBCT 작업 현황

기준일: 2026-11-08. 저장된 실행 결과·검증 JSON·환자별 비교 CSV를 확인해 정리했다. 이번 상태 정리를 위해 새 추론이나 계측값 변경을 실행하지 않았다.

## 촬영 유형에 따른 처리 조건이 생겼는가

현재 확보한 것은 **촬영 조건을 맞춰 비교하는 기준과 추가 검수 후보 지표**다. 촬영 유형별로 서로 다른 전처리·랜드마크 보정값을 적용하는 규칙은 아직 확정하지 않았다.

이번에 처리된 54명은 기록상 모두 Alphard / 80 kVp / 10 mA / 17,000 ms / 0.39 mm 복셀 / FOV 약 199.68×179.4 mm다. 같은 촬영 조건 안에서 자동 검출 오류가 발생한 사례를 비교했으므로, 이번 결과로 촬영 유형 간 성능 차이를 입증할 수는 없다. 촬영 연도·자세·개인차·기록되지 않은 재구성 조건까지 동일하다는 뜻도 아니다.

| 구분 | 현재 상태 | 사용 방식 |
|---|---|---|
| 장비·촬영 조건 확인 | 비교 기준으로 사용 중 | 장비, 관전압·관전류, 노출시간, 복셀 크기, FOV가 일치하는 환자끼리 비교 |
| 계측 방법·QC 기준 | 고정된 방법으로 실행 중 | 환자가 추가돼도 같은 정의·좌표계·기존 QC 기준을 재사용 |
| 국소 밝기·경계·공간 연결 형태 | 탐색 지표 확보 | 원본 영상과 함께 추가 검수가 필요한 원인 후보를 확인 |
| 촬영 유형별 전처리·모델·보정 분기 | 미확정 | 서로 다른 유형의 충분한 사례와 별도 검증 없이 자동 적용하지 않음 |
| 검증된 해부학적 수정 좌표 | 미확정 | 현재 3명의 좌표는 AI 영상 검토 후보로 보존, 최종 분석에 적용하지 않음 |

현재 처리 흐름은 촬영 조건 확인 → 공통 파이프라인 → 거리 QC → 원본 단면·국소 분포 검토 → 확인된 수정 좌표의 별도 재계측이다. 픽셀 분포만으로 촬영 유형을 자동 분류하거나 보정하지 않는다.

## 검증과 다음 순서

기존 실행(P_78 제외 전)의 검증 JSON에서 포함 명단 55명, 실제 처리 54명, 제외 환자 처리 0명, 원본 랜드마크 보존, 후보의 본 계측 적용 0건, 로컬 HTML 링크 유효성을 확인했다. 환자별 캐시 재사용도 P_20에서 확인됐다. 좌표계·영상 단면 대응·제외 명단 차단·원본 복셀 처리에 대한 테스트가 작성돼 있다.

4. Po 사례의 모델 입력·탐색 경로·종료 상태를 확인해 국소 영상 특성과 알고리즘 실패를 구분한다. 원본 분포만으로 전처리 규칙을 변경하지 않는다.
