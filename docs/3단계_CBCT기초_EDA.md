### 표시 기준: "보통 퍼진 정도의 3.5배보다 멀면 표시"

연속 지표는 **로버스트 z**로 봅니다. 83명이 보통 퍼져 있는 정도를 기준으로, 거기서 지나치게 멀리 떨어진 환자를 표시하는 방법입니다.

| 단계 | 뜻 |
|---|---|
| 중앙값 | 83명을 줄 세운 한가운데 값. 평균과 달리 튀는 값에 끌려가지 않음 |
| MAD | 각 환자가 중앙값에서 떨어진 거리들의 중앙값 = "전형적인 환자가 떨어진 거리" |
| × 1.4826 | 정규분포라면 표준편차(SD)와 같아지게 맞추는 보정 |
| z | (그 환자 값 − 중앙값) ÷ (1.4826 × MAD). 보통 퍼짐의 몇 배만큼 떨어졌는지 |
| 기준 | **\|z\| > 3.5**면 표시 (관례적 기준). 그림의 점선 = 중앙값 ± 3.5 × 1.4826 × MAD |

- 예: 잡음은 중앙값 약 37.5, 점선 약 29와 46. P_50은 약 48.8로 z ≈ 4.7 → 표시.
- 평균·SD를 안 쓰는 이유: 튀는 환자가 평균과 SD를 부풀려 기준선이 넓어지고, 정작 튀는 환자가 기준 안에 들어와 버리기 때문.
- 거의 모든 환자가 같은 값이면 MAD가 0이라 z를 계산할 수 없습니다 (예: 촬영 범위). 이런 지표는 다른 규칙을 씁니다.

| 기준 종류 | 적용 지표 |
|---|---|
| 로버스트 z \|z\| > 3.5 | 영상 품질 전부, 자세·교합 전부, 분할 부피·덩어리 수, 촬영 범위 |
| 다수값과 다르면 표시 | 장비, 관전압, 복셀 크기, 행렬 |
| 가장 큰 덩어리 비율 < 0.95 | 분할 4개 구조 (대부분 0.99 이상이라 z를 쓰면 너무 예민해짐) |
| 영상 경계에 닿으면 표시 | 하악, 상악 |
| 표시하지 않고 집단 특성으로 보고 | 상기도 아래 경계 접촉(83명 전원), 두개저 경계 접촉 |

**v1 → v2 규칙 수정 (10/28):** v1은 83명 전원을 표시해서 우선순위를 가릴 수 없었습니다. 계산은 그대로 두고 규칙만 고쳤습니다.
- 상기도 아래 접촉과 두개저 접촉은 환자별 표시에서 빼고 집단 결과로 보고합니다.
- 경계 접촉은 가장 큰 덩어리 기준으로만 봅니다 (떨어진 작은 조각 제외).
- 가장 큰 덩어리 비율은 z 대신 절대 기준 0.95를 씁니다.
- **철회:** v1의 "하악 아래 잘림 의심 22명"은 작은 조각을 센 것이었습니다. 가장 큰 덩어리 기준으로는 0명입니다.

|---|---|---|---|
| 하악, 상악 | 83명 모두 닿지 않음 | 구조가 영상 안에 다 들어옴 | 0명 |
| 상기도 | **83명 모두 아래 경계에 닿음** | 하인두 아래쪽이 잘렸을 수 있음. 기도 분석은 영상 안에서 범위를 따로 정해야 함 | 집단 특성으로 보고 |

### ⑤ 분할 품질 (S_): AMASSS 분할이 조각나거나 엉뚱한 곳을 잡지 않았나

구조 4개(하악, 상악, 상기도, 두개저) × 지표 3개입니다.

| 지표 | 묻는 것 | 어떻게 쟀나 | 표시 기준 |
|---|---|---|---|
| 부피 (`S_<구조>_vol_cc`) | 크기가 이상하지 않나 | 마스크 복셀 수 × 복셀 하나의 부피 (cc) | \|z\| > 3.5 |
| 덩어리 수 (`S_<구조>_ncomp`) | 조각나지 않았나 | 서로 떨어진 덩어리 개수. 많으면 분할이 조각났거나 엉뚱한 곳(예: 상악동)까지 잡은 것일 수 있음 | \|z\| > 3.5 |
| 가장 큰 덩어리 비율 (`S_<구조>_largest_frac`) | 한 덩어리로 잘 잡혔나 | 가장 큰 덩어리 부피 ÷ 전체 부피. 1에 가까울수록 한 덩어리 | < 0.95 |

| 결과 | 하악 | 상악 | 상기도 | 두개저 |
|---|---|---|---|---|
| 부피 중앙값 (범위, cc) | 69 (48~104) | 59 (41~81) | 31 (14~80) | 109 (80~151) |
| 부피 표시 | 0명 | 0명 | P_44 | 0명 |
| 덩어리 수 표시 | 0명 | 3명 (P_37, 56, 68) | 6명 (P_18, 22, 31, 40, 67, 73) | 0명 |
| 가장 큰 덩어리 비율 < 0.95 | 0명 | 0명 | 2명 (P_22, 24) | 9명 (P_27, 29, 37, 47, 48, 51, 58, 83, 86) |

**정리:**
- 하악 분할은 깨끗합니다 (표시 0명).
- **상기도**는 덩어리가 여러 개인 환자가 있습니다. P_22를 열어 보니 상악동 안까지 기도로 잡혀 있었습니다 (3-6).
- **두개저**는 조각난 환자가 9명입니다. P_51을 보면 촬영 범위 뒤쪽 끝에서 잘린 뼈 조각이었습니다 (3-6).
- 분포에서 튀는 값이 곧 오류는 아닙니다. 하악이 실제로 큰 환자는 부피가 큽니다. 그래서 자동으로 빼지 않고 영상을 확인합니다.

### ⑥ 엑셀 계측값 대조: 자동 분할 부피가 전문가 기도 계측과 같이 움직이나
