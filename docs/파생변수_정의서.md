# 파생변수 정의서

CBCT·PSG 자료에서 계산한 모든 파생변수의 정의를 기록하는 문서입니다. **새 파생변수를 만들면 반드시 이 문서에 행을 추가합니다.**

- 최초 작성: 2026-11-15
- 환자별 결측 수: 빌드할 때마다 자동으로 갱신되는 `Result_py/features/v1/feature_catalog.csv`의 `n` 열을 보세요. 이 문서에는 알려진 결측 원인만 적습니다.
- 자동 점검: `python build_features.py`는 `features.csv`의 열 가운데 이 문서 표의 **변수명** 칸에 없는 열을 `summary.json`의 `undocumented`에 적고 경고합니다.

## 기록 규칙

| 칸 | 쓰는 법 |
|---|---|
| 변수명 | 결과 파일의 **실제 열 이름**을 백틱으로 씁니다. 같은 규칙의 묶음은 `*`를 씁니다(예: `AW_p*`). 한 칸에 여러 개면 쉼표로 나눕니다 |
| 정의 | 계산식과 기준점·경계까지 적습니다. 다른 사람이 같은 값을 다시 계산할 수 있어야 합니다 |
| 출처 | 원재료를 만든 프로그램(ALI-CBCT, AMASSS, TotalSegmentator, 치아 분할, 밝기 규칙, 엑셀) |
| 단위 | mm, mm², mm³, mL, °, %, 비(단위 없음), 점수 |
| 역할 | 아래 분석 역할 중 하나 |
| 코드 → 파일 | 계산 스크립트 → 결과 파일 |
| 추가일 | YYYY-MM-DD |
| 한계 | 알려진 결측 원인, 측정 신뢰도, 정의가 불분명한 점 |

### 분석 역할
| 역할 | 뜻 |
|---|---|
| **사전 가설** | 결과를 보기 전에 정한 주 가설 피처. 2-B(나이·성별·BMI + 피처 → OSA)에 넣습니다 |
| **2-A 전용** | 골격 → 기도 단계에서만 씁니다. 기도 길이·높이와 정의가 겹쳐 OSA 모델에는 넣지 않습니다 |
| **기도·매개** | 기도 지표. 2-A의 결과 변수로 쓰고 2-B에서는 뺍니다 |
| **기준선** | 기존 Roh 골격 지표. 새 피처와 비교하는 기준입니다 |
| **탐색** | 다중검정(FDR) 보정 후 보고합니다. 확증 근거로 쓰지 않습니다 |
| **입력·보조** | 다른 피처를 만드는 재료나 계산 보조값. 회귀에 직접 넣지 않습니다 |

### 공통 좌표계
- **정중 좌표계:** 원점은 뒤코가시(PNS), 축은 좌·앞·위(mm)입니다. 귓구멍 점(Po)을 쓰지 않고 N·S·Ba·ANS·PNS 다섯 점으로 정중면을 잡습니다. 코드는 `cbct_eb_detect.midline_frame`입니다.
- **머리 좌표계:** 원점은 코뿌리점(N)이고, FH(귓구멍·눈밑점 대칭 보정 후)와 정중면으로 축을 잡습니다. 코드는 `osa.ceph.head_frame`입니다.
