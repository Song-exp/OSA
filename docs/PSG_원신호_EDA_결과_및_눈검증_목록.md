## 3. 자동 판독과 수동 판독: 수동 판독을 쓰고 리포트와 대조

**배경**
- Nox `Data.ndb`에는 장비 자동 판독(Automatic)과 기사 수동 판독(Manual)이 함께 저장되어 있습니다.
- 자동 판독은 초안이고, 기사가 그것을 고친 결과가 수동 판독입니다.
- **둘이 다른 것은 정상적인 판독 과정이며 오류가 아닙니다.** 문제가 되는 것은 기존 코드나 뷰어가 두 층을 **섞어서** 쓸 때입니다.

**규칙**
- 같은 30초에 두 층이 다 있으면 **Manual을 씁니다.**
- 사건은 Manual 층에서 분석구간 안, 수면 중에 시작한 것만 셉니다(`PSG_엑셀_불일치_검증.md`의 후보 규칙).
