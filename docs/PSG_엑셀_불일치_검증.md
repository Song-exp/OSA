# PSG 엑셀 불일치 검증 — 엑셀 ↔ 리포트 PDF ↔ 원본 판독

> `PSG Excel EDA.md`에서 찾은 AHI/RDI 재계산 불일치(87명 중 42명, |ΔAHI|>1)의 원인을 파일 대조로 확인한 결과입니다.
> 스크립트: `python/psg_reconcile.py` · 결과: `Result_py/psg_reconcile.csv`(환자별 대조), `psg_reports.csv`(리포트 109개), `psg_verified.csv`(검증 데이터셋)
> 원본 엑셀과 원본 PSG는 읽기만 했습니다. 결과 파일에 이름·생년월일·등록번호는 없습니다.

## 한 줄 결론

**엑셀의 요약값(TST·AHI·RDI·ODI·최저 SpO₂)은 84명이 병원 리포트와 같습니다. 문제는 사건 개수 6열(Q~V)입니다.**
이 열은 87명 전원이 기존 MATLAB/Python 코드가 원본 판독 파일에서 센 값과 똑같습니다. 그래서 일부 환자는 리포트와 다른 날 검사이거나, 기사 최종 판독이 아닌 값입니다.
리포트에 적힌 개수로 바꾸면 재계산 불일치는 42명에서 3명으로 줄고, 남은 3명도 리포트 자체의 분모 차이입니다.

## 1. 확인 방법

| 데이터 | 읽은 것 | 출처 |
|---|---|---|
| 엑셀 | L~V열 (머리글 이름을 코드에서 검사) | `Patient_Info_Data_87명_261019.xlsx` |
| 리포트 PDF | Study Date, TST, 총기록시간, AHI, RDI(머리말·요약표 두 칸), ODI, 최저 SpO₂, OA·CA·MA·Hypopnea·RERA·호흡각성 개수, 소견란의 "AHI=이전→현재" | 각 폴더 `Report*.pdf` (87명, 109개) |
| 원본 판독 Embla(E) | 기록일, 사건 개수 | `EN-Apnea Events.txt` |
| 원본 판독 Nox(N) | 기록일, 판독층별 개수 (Automatic / Manual / 기존 코드 방식 / 후보 규칙) | `Data.ndb` |

**판정 기준**
- **엑셀 요약값 ↔ 리포트:** TST ±0.6분, AHI ±0.1이면 같은 검사로 판정
- **원본 판독 ↔ 리포트:** 기록일 ±1일이면 같은 검사로 판정. 개수 차이는 E는 2%, N은 5% 이내를 허용

**Nox 후보 규칙**
- 기사(Manual) 마커 중에서, 분석 구간(`period-analysisstart~stop`) 안에 있고 이벤트 시작 시각이 수면 중인 것만 셉니다.
- 수면단계는 30초 구간마다 Manual이 Automatic을 덮어씁니다.
- 이 규칙은 P_12와 P_59로 맞춘 뒤 나머지 Nox 환자에게 그대로 적용했습니다.
