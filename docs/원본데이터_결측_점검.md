## 2. PSG (87명: E 55, N 32)

### 2-1. 원신호

| 항목 | 결과 |
|---|---|
| 기록 길이 | 5.3~8.9시간 |
| 핵심 채널 (SpO2, 비강 압력, 흉부·복부 호흡노력, EEG, 턱 근전도) | 87명 모두 있음 |
| ECG, 다리 근전도, 서미스터 | P_20만 없음 |
| EOG | P_2, P_20, P_39 없음 |
| 자세 채널 | 87명 모두 있음 |

**P_20**은 채널 이름이 `*_PDS`인 휴대형 장비 기록입니다. 그래서 `missing_raw.csv`에는 채널 이름표에 매칭되지 않아 모든 채널이 없는 것으로 나옵니다. 실제로 있는 채널은 다음과 같습니다.
- SpO2 3 Hz
- 비강 기류, 흉부·복부 50 Hz
- EEG 1개, EOG 1개, 턱 근전도
- 자세

**신호가 비는 구간** (기록 시간 대비, 1% 초과만)

| 비율 | 환자 |
|---|---|
| 10% 이상 | **P_68 (12.4%)** |
| 3~5% | P_44, P_49 (SpO2만), P_78, P_80 |
| 1~3% | P_15, P_23, P_39, P_51, P_55, P_57, P_60, P_66, P_71, P_72, P_77, P_82, P_83, P_84, P_85, P_87 |

- **SpO2 이상값**(50% 미만 또는 100% 초과)은 최대 4.3%(P_43)입니다. 1%를 넘는 환자는 P_35, P_43, P_79 세 명입니다.

### 2-2. 판독 파일

| 정보 | E (55명) | N (32명) |
|---|---|---|
| 수면단계 | 55 | 32 |
| 호흡 이벤트 | 55 | 32 |
| 자발 각성 | **0** | 31 |
| 산소저하 이벤트 | **0** | 32 |
| 자세 | 52 (P_3, P_41, P_65 없음) | 32 |

- E 판독 파일(RemLogic 내보내기)에는 이벤트 종류가 6가지만 들어 있습니다. 그래서 **ArI는 원본으로 다시 계산할 수 없고**, **ODI는 SpO2 원신호에서 3% 하강 규칙으로 직접 계산해야** 합니다.
- ESS(설문)는 원 검사값이 아니어서 리포트에만 있습니다.

### 2-3. 결측과 별개인 정합성 문제 (품질점검 문서 참고)

- **N 판독층 규칙이 미완성입니다.** 후보 규칙으로 계산한 이벤트 수가 11명에서 리포트와 5% 넘게 다릅니다.
- **엑셀 값과 원신호가 다른 검사인 환자가 11명입니다.** 그중 7명(P_9, P_26, P_41, P_42, P_43, P_47, P_77)은 원신호 검사의 리포트가 없습니다.

## 3. CBCT (87명)

### 3-1. 볼륨

| 항목 | 결과 |
|---|---|
| 상위 폴더 시리즈 | 87명 모두 1개 |
| 슬라이스 연속성 | 87명 모두 빠진 슬라이스 없이 등간격, 정육면체 voxel |
| 촬영 범위 | 85명은 200×200×179 mm. **P_50은 154 mm, P_78은 102 mm 정육면체** |
| 하위 폴더 | P_34 1개, P_39 1개, P_40 2개 |
| 확인 안 한 것 | 금속 보철·교정장치에 의한 잡음. 파일럿 때 눈으로 확인 |

- 엑셀에서 NAV가 빠진 환자는 29명, PAV가 빠진 환자는 약 60명입니다. 이 중 P_78을 빼면 촬영 범위는 충분합니다. 그래서 **원본 결측이 아니라 "측정하지 않음"**으로 보입니다.

### 3-2. P_50, P_78: 좌표 확정 단계에서 판정

지금 제외하지 않습니다. 파일럿에서 랜드마크를 찍어 보고, 범위 밖이라 잃는 랜드마크에 따라 **변수별로** 포함 여부를 정합니다.

| 잃는 랜드마크 (예상) | 영향받는 변수 |
|---|---|
| Po, Or | FH 기준 변수 (MP-FH, Nperp-A, Nperp-Pog). 좌표계를 대체 정의로 바꿀지 검토 |
| Ba, Na | 정중시상면, NAV 상한 |
| Eb, 인두 하부 | PAV, PMCA, PAL |
| 영향 적을 것 | ANB, TDI, PHI, NCWR (관상 단면, 정중부 점) |

### 3-3. P_39 조사 결과

**결론: 받은 데이터 안에는 P_39 본인의 CBCT가 어떤 형식으로도 없습니다.**

| 확인 | 방법 | 결과 |
|---|---|---|
| CBCT 폴더 전체 | 91개 시리즈(상위 87, 하위 4)의 헤더를 P_39 리포트의 생년월일, 성별, 등록번호와 비교 | 일치하는 시리즈 없음 |
| P_39 상위 폴더 | 같은 비교 | 성별만 같음. 촬영 당시 51세(2021년) |
| P_39 하위 폴더 | 같은 비교 | P_24의 2022년 촬영본 |
| 다른 형식의 CBCT 파일 | 상위 OSA 폴더 전체의 확장자 집계 | CBCT 전용 형식(.inv, .o3d, .mcs, .nii, .nrrd, .stl, 압축파일) 없음. .dcm은 Data/CBCT에만 있음 (나머지는 파이썬 라이브러리 테스트 파일) |
| 애매한 형식 | 위치와 크기 확인 | .dat 103개와 .jpg 50개는 전부 Data/PSG에 있고 jpg는 0.5~1 MB. .db 65개는 윈도우 썸네일 캐시. P_39 폴더의 .ede 4개는 1~4 KB짜리 Embla 부속 파일 |
| 엑셀 | 나이, 측정값 | 2011년 PSG 당시 15세. **CBCT 측정값 11개가 모두 있음** |

- P_39는 2021년에 25세 전후여야 하므로, 상위 폴더 영상(51세)은 헤더 입력 실수가 아니라 다른 사람의 영상입니다.
- **확인하지 않은 범위**
  - 헤더만 비교했고 영상 내용은 비교하지 않았습니다. 다만 나머지 시리즈는 모두 주인이 확인됐습니다.
  - 프로젝트 폴더 밖(원본 드라이브, 병원 서버)은 보지 않았습니다.
- **엑셀에 P_39 측정값이 있다는 점이 단서입니다.** 가능성은 두 가지입니다.
  1. 측정할 때는 본인 영상이 있었다 → 원본에서 다시 받으면 복구할 수 있음
  2. 처음부터 잘못된 영상으로 쟀다 → 엑셀의 P_39 CBCT 값도 틀림
  - 자동 측정 파이프라인이 완성되면 상위 폴더 영상을 재서 엑셀과 비교할 수 있습니다. 값이 맞으면 2번입니다.
  - 데이터 관리자에게 묻는 편이 더 빠릅니다.

### 3-4. 받은 데이터에 없는 측정 기록

- **랜드마크 좌표 파일도 없습니다.** Invivo나 Mimics 프로젝트 파일이 없기 때문입니다.
- 그래서 엑셀은 최종 계측값만 검증할 수 있고, 랜드마크는 다변수 일관성, 해부학 점검, 직접 검수로 대신 확인합니다 (`CBCT_측정_계획.md` 7-3).

2. **엑셀 CBCT 측정에 쓴 Invivo/Mimics 프로젝트 파일**(랜드마크 좌표 포함)이 남아 있는지. 남아 있다면 그 좌표가 폴더의 같은 CBCT 시리즈에 대응하는지도 확인합니다.
3. NAV, PAV가 빠진 환자는 측정하지 않은 것인지, 측정할 수 없었던 것인지.
4. P_20을 휴대형 장비로 검사한 이유. 같은 기간의 정규 검사가 있는지도 확인합니다.
