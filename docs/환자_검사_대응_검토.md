# 환자·검사 대응표 검토 방법

작성: 2026-11-05. 수정: 2026-11-07 (환자 일치 검수와 PSG 값 일치 검수의 두 파일로 통합). CBCT↔엑셀↔PSG 독립 대조를 유지한다. 87명 전체를 대상으로 원본 연결을 확인하며 분석 표본 확정이나 자동 제외 단계는 아니다.

## 이번 대조 집계

| 항목 | 결과 |
|---|---|
| 환자별 대응표·근거 문서 | 87명 전원 |
| CBCT↔PSG 등록번호 보조 대조 | 일치 61명 / 불일치 26명. 엑셀 대응 결과 아님 |
| 엑셀↔CBCT | 식별정보 일치 83명 / 성별 불일치 2명 / 생년월일 불일치 2명 |
| 엑셀↔PSG | 식별정보 일치 85명 / 일부 리포트 성별 불일치 2명 |
| 엑셀 PSG 요약값 대응 리포트 | 확인 84명 / 미확인 3명 |
| 엑셀↔원신호 검사 | 동일 73명 / 다른 검사 11명 / 엑셀 검사 미확인 3명 |
| 원신호↔리포트 검사 | 연결 80명 / 해당 리포트 없음 7명 |
| 엑셀↔대응 리포트 요약 5종 | 모두 일치 81명 / 일부 불일치 3명 / 비교 불가 3명 |
| 엑셀↔대응 리포트 사건 6종 | 모두 일치 30명 / 일부 불일치 54명 / 비교 불가 3명 |

기존 61명 일치·26명 불일치는 CBCT↔PSG 병원 등록번호의 보조 비교 결과다. 이를 CBCT↔엑셀의 대응 판정으로 사용하는 것은 정정했다. 독립 대응 판정과 보조 비교는 별도 열과 시트에 기록하며, 자동 제외는 하지 않는다.

독립 대조에서 확인이 필요한 사례는 CBCT 성별 P_36·P_85, CBCT 생년월일 P_39·P_59, PSG 일부 리포트 성별 P_8·P_85다. 식별정보 차이 자체로 다른 사람이라고 자동 확정하지 않는다. 최종 검수 파일 2개의 생성 검증은 `review_workbooks_validation.json`에 기록한다.

원본 대조 근거는 변수별 957개 값, 리포트 사본 109개, DICOM 41,585개 헤더 감사 결과다. CSV·원본 파일 목록·현재 근거 문서와 11지표 시각화는 유지한다. 이전 통합 엑셀과 이전 버전 백업·검증 기록은 새 파일 검증 후 삭제한다.

## 결과 위치

- `Result_py/patient_matching/환자 일치 검수.xlsx`: `통합·최종판단` / `CBCT` / `PSG`의 3개 시트. 통합은 87명, CBCT는 시리즈별, PSG는 보고서 또는 원신호 자료별 행이다. 직접 대조 사실·보조 근거·검토 해석·수기 최종판단을 구분한다. P_85의 현재 연결검사와 과거 보고서 성별 차이를 별도 행으로 본다.
- `Result_py/patient_matching/PSG 값 일치 검수.xlsx`: `통합·최종판단` / `PSG`의 2개 시트. 통합은 87명, 상세는 환자×검사×11개 지표다. 서로 다른 검사와 검사일 미확인 엑셀값은 행을 분리한다. 엑셀값 957개와 원본값 957개를 보존하며 같은 검사 73명에 대해서만 엑셀–원본 차이 803개를 계산한다. 전체 상세는 1,111행이다.
- `Result_py/patient_matching/index.html`: 전체 목차. 환자 번호를 누르면 해당 환자의 근거 문서로 이동.
- `Result_py/patient_matching/patients/P_n/evidence.html`: 개별 환자의 판정, PSG 원값 대조, CBCT 시리즈, 원본 파일 링크.
- `patients/P_n/reports/`: 리포트 PDF 사본. 원본과 SHA256 동일성을 확인한다.
- `patients/P_n/source_files.csv`: 해당 환자 원본 파일 전체 목록. 대용량 영상·파형은 복제하지 않고 원래 경로를 보존한다.

환자별 결과와 보고서 사본은 모두 git 제외 경로에 저장한다. 이 문서에는 환자 식별정보나 개별 측정값을 넣지 않는다.

## 판정 기준

### 연구번호와 병원 등록번호를 구분

엑셀 No.는 연구번호이며, PSG·CBCT 열의 O 표시는 자료 보유 표시다. 엑셀에는 병원 등록번호가 없다.

따라서 No.와 각 P_n 폴더를 연결한 후, 엑셀의 생년월일 YYMMDD·문자 성별을 CBCT DICOM 및 PSG 리포트와 각각 독립적으로 대조한다. 숫자 성별 코드 오류와 섞지 않는다. 엑셀에 생년월일의 세기와 병원 등록번호가 없다는 한계를 남긴다. 연구번호 배정 일치, 식별정보 일치, 동일인 절대 확정은 구분한다.

### CBCT

엑셀 No.와 CBCT 폴더 P_n, 엑셀 생년월일·문자 성별과 상위 DICOM 헤더를 직접 비교한다. PSG 리포트는 이 판정의 근거로 사용하지 않는다. 기존 전수 헤더 감사 결과와 대표 헤더 해시를 이용해 시리즈 및 폴더 내부 혼입을 추적한다.

- 생년월일 YYMMDD·성별이 모두 같으면 식별정보 일치.
- 생년월일 또는 성별이 다르면 해당 필드의 불일치로 기록하며, 다른 사람으로 자동 확정하지 않는다.
- 대조에 필요한 필드가 없으면 확인 불가.
- 하위 폴더는 별도 시리즈로 기록하고 상위 영상과 분리한다.

CBCT PatientID↔PSG 리포트 등록번호는 `검사간_보조대조`에만 기록한다. 공백만 제거하고 선행 0·접두사를 임의로 바꾸지 않는다. 이 결과가 직접 대조 결과를 덮어쓰지 않는다.

계측값 대조, 랜드마크·분할 정확도 검증, PSG와의 간격에 따른 제외는 이번 범위에 포함하지 않는다.

### PSG

환자, 검사, 값의 판정을 분리한다.

1. 환자: 엑셀 연구번호·생년월일·문자 성별을 PSG 폴더와 각 리포트에 직접 대조한다. CBCT 정보는 판정에 사용하지 않는다. 복수 리포트 중 하나라도 성별이 다르면 필드 불일치를 표시하고 리포트별 세부 결과를 남긴다. 원신호 내부 환자 ID는 별도 검증하지 않았으므로 폴더·검사시각을 통한 연결임을 표시한다.
2. 엑셀 대응 검사: 엑셀에 검사일이 없으므로 TST ±0.6분 및 AHI ±0.1을 함께 만족하는 유일한 리포트 후보를 연결한다. 이는 값에 기초한 연결이며 독립적인 날짜 검증이 아니다. 후보가 없거나 복수면 확정하지 않는다.
3. 원신호 대응 검사: SpO2 원본 파일의 실제 기록 시작·종료 시각을 직접 읽는다. 정오 전 시작은 전날 밤 날짜도 검사일 후보로 허용한다. 단순히 ±1일이라는 이유만으로 연결하지 않는다. 복수 리포트 후보는 자동 선택하지 않는다.
4. 값: 엑셀과 대응 리포트의 TST·AHI·RDI·ODI·최저 SpO2 및 사건 6종을 개별 비교한다. 리포트 내부의 다른 RDI 값 등은 별도로 보존한다.

| 변수 | 일치 허용 차이 |
|---|---|
| TST | 0.6분 |
| AHI | 0.1회/시간 |
| RDI | 0.15회/시간 |
| ODI, 최저 SpO2 | 표기값 정확 일치 |
| 사건 6종 | 정수 개수 정확 일치 |

차이는 엑셀−리포트 방향이다. 값으로 리포트를 찾은 TST·AHI의 일치를 독립적인 정확도 검증으로 해석하지 않는다.

원본 판독값은 같은 원신호 검사에 대응하는 리포트와 별도 비교한다. Embla는 TXT 사건 수, Nox는 기존 Manual 우선 후보 규칙이다. Nox 후보 규칙은 최종 판독이 확정됐다는 뜻이 아니다. 차이를 그대로 보여주며 임의의 임상 허용오차로 통과시키지 않는다.

초기 대응표에서는 파형의 검사시각만 확인했다. 후속 보완본에서는 기존 수면단계의 TST, 기존 사건 수/TST 기반 AHI·RDI 재계산, SpO2 파형의 참고 ODI 및 최저 SpO2를 추가했다. 무호흡·저호흡이나 수면단계를 새로 판독한 것은 아니다. 전 채널 품질 검증과도 구분한다.

AHI·RDI 재계산값은 Embla TXT 전체 사건 수 또는 Nox Manual 우선 후보 규칙을 사용하므로, 최종 판독의 사건 범위·분모와 다를 수 있다. ODI는 장비의 공식 알고리즘을 재현한 값이 아니다. LSaO2는 수면 중 값을 주값으로 두고 전체 기록 최저도 별도 보존한다. 값을 일치시키려고 두 최저값 중 하나를 사후 선택하지 않는다. 파형 유효 범위는 50~100%로 정한 기존 코드의 기준이다.

## 사람 검토 순서

1. 통합 대응표에서 CBCT ID, PSG 환자, 엑셀 검사, 원신호 검사, 요약값, 사건 수의 판정을 각각 확인한다.
2. 환자별 근거 문서에서 연결된 PDF와 원본 경로를 확인한다.
3. 불일치는 어떤 비교에서 발생했는지 기록한다. ID 차이와 다른 사람, 검사 날짜 차이와 값 오류를 구분한다.
4. 검토 완료 여부와 의견을 기록한다. 출처 없는 값은 비워 두고, 원본 값을 교체하지 않는다.
5. 87명 검토 후 별도로 분석 검사 선택과 포함·제외 기준을 결정한다.

## 오차 분포와 허용차 후보 검토

`Result_py/patient_matching/figures/psg_error_review.html`에서 요약 5종과 사건 수 6종, 총 11개 지표의 그래프를 크게 보고 후보 허용차와 세로축 확대 범위를 조절한다. 11개 지표로 재집계한 초기 불일치군 72명과 동일 검사 전체 73명을 전환할 수 있다. 후보를 변경해도 초기 표시군은 고정되며, 후보 초과 인원은 전체 73명을 기준으로 갱신한다. 사건 수는 OA(폐쇄성 무호흡), CA(중추성 무호흡), MA(혼합성 무호흡), H(저호흡), RERA, RESP(호흡각성)이며 초기 후보 허용차는 0건이다.

- 중앙 95% 경계: 현재 표시군의 차이 분포 2.5~97.5백분위.
- 절대차 P95 후보: 전체 73명의 환자별 세 쌍 차이 중 최대 절대차의 95백분위. 불일치군을 먼저 고른 데 따른 선택 영향을 줄이기 위해 전체 표본에서 구한다.
- 녹색 영역은 후보 허용차, 빨간 점은 후보 밖의 값이다. 원본 산출 방법 차이도 포함되므로 임상 오류를 뜻하지 않는다.
- 중앙 확대에서 벗어난 점은 인원수로 표시하며 전체 범위 보기에서 확인한다.
- 지표당 한 페이지인 PDF는 `psg_error_review.pdf`, 큰 PNG는 `psg_error_review_TST.png` 등의 이름으로 저장한다.
- 임상 허용오차를 자동 확정하지 않는다. 검토한 후보와 환자별 초과 여부는 화면에서 CSV로 저장한다.

재생성: `.venv/Scripts/python.exe python/psg_error_review.py`. 이전 5패널 축소 그림은 대체본으로 교체했다.

검수 엑셀만 재생성할 때는 `.venv/Scripts/python.exe python/build_review_workbooks.py`를 실행한다. 기존 새 파일 2개의 수기 필드는 환자·자료·검사·지표 키를 이용해 보존한다. 파란 셀은 수기 검수 영역이다. 통합의 최종판단은 환자 단위 결론이며 상세의 최종판단은 개별 자료·지표에 대한 판단이다. 분석 포함 여부나 임상 오류를 자동 확정하지 않는다.

## 재실행

프로젝트 루트에서:

```powershell
.venv/Scripts/python.exe python/psg_reconcile.py
.venv/Scripts/python.exe python/patient_matching.py
.venv/Scripts/python.exe python/psg_waveform_check.py
.venv/Scripts/python.exe python/supplement_psg_values.py
```

재실행은 자동 생성 결과와 검토 의견 열을 덮어쓸 수 있으므로 검토자가 작성한 결과는 다른 이름으로 보관한다. 원본 엑셀·PSG·CBCT는 수정하거나 이동하지 않는다.
