# 피처 원천별 분류표

작성: 2026-11-16. 지금까지 만든 모든 피처와 파생변수를 **raw 데이터와 그것을 처리한 도구** 기준으로 분류한 표다.
- 변수마다 계산식과 한계는 [파생변수 정의서](파생변수_정의서.md)에 있고, 이 문서는 "어디서 왔는가"와 "지금 어떻게 쓰는가"를 정리한다.
- 분석 결론은 [Step 1](Step1_작업일지.md)·[Step 2](Step2_작업일지.md)·[Step 3](Step3_작업일지.md) 작업일지에 있다.

## 0. 원천 체계

| 원천 raw 데이터 | 처리 도구 | 분류 | 피처 수(대략) |
|---|---|---|---|
| 연구실 엑셀 (임상·PSG·수작업 CBCT 계측) | 없음 (원값) | **A. 엑셀 원자료** | 임상 3, PSG 결과 10+, 수작업 계측 11+14 |
| CBCT 영상 (`nrrd/P_n.nrrd`) | **ALI-CBCT** 기준점 모델 | **B. CBCT 기준점(ALI) 기반** | 좌표 25 + 거리·각도 약 20 |
| CBCT 영상 | 자체 **밝기(HU) 규칙** (공기 −1200~−400, 뼈 덩어리) | **C. 밝기 규칙 기반 (기도·설골·Eb)** | 약 40 (단면 프로파일 20 포함) |
| CBCT 영상 | **AMASSS** 분할 (하악 MAND, 상악 MAX, 두개저 CB, 상기도 UAW) | **D. AMASSS 분할 기반 (형태 벡터·부피·과두)** | SSM 점수 + 부위 ROI 48 + 약 20 |
| CBCT 영상 | 공개 nnU-Net **치아 분할** (UNIVERSALLAB) + ALI 치아 점 | **E. 치아 분할 기반** | 약 25 |
| CBCT 영상 | **TotalSegmentator** (비강·인두·연구개·혀·저작근·부비동) | **F. TotalSegmentator 분할 기반** | 약 60 |
| 위 B~F 결과 | 통계 모델 (요인분석, PLS, PCA) | **G. 통계적 2차 파생** | 약 25 |
| 위 A~G 결과 | 분석 스크립트 (비교·보정·결과 변환) | **H. 분석용 변수 (비교·등급·결과 변환)** | 약 30 |

- **좌표계:** 정중 좌표계(PNS 원점, Po 미사용)와 머리 좌표계(N 원점, FH 사용) 두 가지다. FH를 쓰는 피처는 표에 **[FH]**로 표시했다. Step 1에서 FH 방향 오차가 확인됐다.
- **상태 표기:**
  - **확정 인자** = 최종 OSA 모델에 들어간 것
  - **후보** = 사전 기준은 통과했으나 확정 전
  - **기준선** = 비교 기준
  - **결과 변수**
  - **탐색** = FDR 보고만
  - **보조** = 다른 피처의 재료
  - **보류** = 아직 피처 표에 넣지 않음
