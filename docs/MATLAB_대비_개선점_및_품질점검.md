## 2. MATLAB 대비 개선점

### 2-1. 그대로 재현한 부분 (검증 완료)

| 기능 | MATLAB | Python | 검증 |
|---|---|---|---|
| EBM/NDF 원신호 읽기 | `EbmRead`, `PSG_read_*` | `osa/psg_read.py` | 신호값 동일, 시간 차이 ≤0.12 µs |
| 판독 이벤트·수면단계 | `PSG_Events.m` | `osa/psg_events.py` | 이벤트, 수면단계, 이벤트 개수 동일 |

| 그림 | `.fig` (탭) | PNG (탭마다 1장) | 같은 구성 (수면단계, 이벤트 음영, 단절 표시) |

### 2-2. 개선한 부분

| 항목 | MATLAB | Python | 효과 |
|---|---|---|---|
| 다른 날 채널 제외 | 폴더 이름 `P_43_PSG_E`에 고정. 번호가 바뀌어 작동 안 함 → P_23 처리 실패 | 채널 시작 시각이 중앙값과 12시간 넘게 다르면 제외 | P_23 처리 가능. 87명 중 해당자는 P_23뿐 |
| 실행 방식 | 경로가 코드에 박혀 있고(`E:\...`), 폴더 선택 창이 뜸 | 프로젝트 기준 상대경로, 명령줄(`python -m osa.batch psg --ids ...`) | 다른 PC나 서버에서 그대로 실행 가능 |

| 저장/불러오기 검증 | 없음 | `test_roundtrip.py` | 저장 손실 없음 확인 |
| **데이터 품질 점검** | 없음 (형식이 이상할 때만 멈춤) | `check_quality.py` (3장) | 본인 확인, 검사일 대조, 판독층 검증 |

### 2-3. 아직 개선하지 않은 부분 (4장 논의 후 반영)

- **Nox 판독층:** 리더(`psg_events.py`)는 아직 MATLAB과 같은 방식입니다. 후보 규칙은 점검 스크립트 안에만 있습니다.
- **CBCT 하위 폴더:** 리더는 MATLAB처럼 시리즈가 2개 이상이면 멈춥니다. 상위 폴더만 읽는 옵션은 아직 없습니다.
- **본인 확인과 검사일 대조:** 점검 단계에서만 합니다. 처리 단계에서 자동으로 제외하지는 않습니다.
- **기존 결과가 있으면 건너뛰는 동작:** MATLAB과 같습니다. 코드가 바뀐 뒤 예전 결과가 남는 문제(E 환자 SpO2 배율)를 막으려면, 결과에 코드 버전을 기록하고 버전이 다르면 다시 만들어야 합니다.

## 4. 걸린 데이터 처리 방안 (논의용)

분석 목적별로 기준이 달라서, 문제마다 선택지와 제안을 적었습니다.

### A. CBCT 본인 아님: P_39
- **제안:** CBCT를 쓰는 모든 분석에서 제외합니다. P_39의 PSG는 사용합니다.
- 엑셀의 P_39 CBCT 측정값도 어느 영상에서 쟀는지 확인될 때까지 제외합니다.
- **문의:** P_39 본인 CBCT의 위치
- 받은 데이터 전체를 찾아봤지만 본인 영상은 없습니다. 조사 내용은 `원본데이터_결측_점검.md` 3-3에 있습니다.

### B. CBCT 하위 폴더 혼입: P_34, P_40
- 상위 폴더는 본인으로 확인됐습니다 (생년월일, 성별 일치).
- **제안:** 리더에 "상위 폴더만 읽기" 옵션을 추가하고, 무시한 하위 폴더는 기록으로 남깁니다. 이러면 두 환자를 분석에 넣을 수 있습니다.
- 하위 폴더에 있는 P_24, P_50, P_59의 다른 날 촬영은 쓰지 않습니다. 각 환자는 본인 폴더의 영상을 씁니다.

### C. CBCT 생년월일 불일치: P_36, P_59
- **제안:** 등록번호가 일치하므로 포함하고, 불일치 사실은 기록만 해 둡니다.

### D. 엑셀과 원신호가 다른 검사: 11명 (가장 중요한 결정)
- 엑셀의 PSG 지표(AHI 등)와 폴더 원신호가 서로 다른 날 밤의 기록입니다.
- **선택지**
  1. **연구용 검사 = 원신호 검사로 통일:** 요약 지표를 원신호 판독에서 다시 계산합니다. E는 리포트와 2% 이내로 검증됐습니다. 그러면 원신호 지표, 요약 지표, CBCT가 같은 밤 기준으로 맞습니다. 단, N 2명(P_42, P_47)은 판독 규칙이 풀려야 합니다.
  2. **엑셀 값을 유지:** 요약 지표 분석에는 엑셀을 쓰고, 원신호 분석에서는 이 11명을 뺍니다.
  3. **11명 제외:** 가장 단순하지만 표본이 줄어듭니다 (87 → 76).
- **제안:** 1번. 새 지표 개발이 원신호 기반이라, 모든 변수가 같은 밤에서 나와야 합니다. 엑셀 값은 비교용으로 따로 둡니다.

### E. PSG 복수 검사: 17명
- 원신호는 모두 최신 검사이고, 일부는 AHI가 크게 줄었습니다 (예: P_19는 13.3 → 2.2). 치료 후 추적 검사일 가능성이 있습니다.
- **제안:** 일단 포함하고 "복수검사" 표시를 남깁니다. 주요 결과는 이 17명을 뺀 민감도 분석으로 확인합니다.
- **문의:** 치료 이력(수술, 양압기, 구강장치)을 알 수 있는지

### F. CBCT와 PSG가 1년 넘게 떨어짐: 13명
- 성인 골격은 비교적 안정적이지만, 기도와 연조직은 체중이나 치료에 따라 달라질 수 있습니다.
- **제안**
  - 골격 지표(ANB, MP-FH, TDI) 분석에는 포함합니다.
  - 기도 지표(NAV, PAV 등)와 PSG의 관계 분석은 1년 이내 환자만 쓰거나 민감도 분석을 합니다.
  - 기준(1년)은 논의가 필요합니다.

### G. N 이벤트 불일치: 후보 규칙으로 5% 넘게 다른 11명
- **제안**
  1. 이벤트 순서와 빈도 같은 **이벤트 단위 분석은 E 55명으로 먼저** 시작합니다. E는 검증됐습니다.
  2. 요약 지표(AHI 등)는 N 환자도 리포트와 엑셀 값을 씁니다.
  3. N 판독 규칙은 `period-analysis` 구간과 삭제 이벤트 처리를 확인해 계속 다듬습니다. 5% 이내가 되는 환자부터 이벤트 분석에 넣습니다.
- **문의:** Nox에서 최종 판독을 저장하고 합치는 방식을 아는 사람이 있는지

### H. PSG 다른 날 채널: P_23
- Python에서 날짜 기준으로 자동 제외합니다. 따로 할 일은 없습니다.
