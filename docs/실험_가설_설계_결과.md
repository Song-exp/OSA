작성: 2026-11-16. 지금까지의 OSA 관련성 실험을 한 표씩 정리했다. **갱신 규칙: 새 실험 결과가 생기면 해당 단계 표에 행을 추가하고, 종합 표와 대기 목록을 함께 고친다.**
- 상세 수치와 시간순 기록: [OSA 관련성 실험기록](OSA_관련성_실험기록.md)
- 단계별 결론: [Step 1](Step1_작업일지.md) · [Step 2](Step2_작업일지.md) · [Step 3](Step3_작업일지.md) · [Step 4](Step4_작업일지.md)
- 피처 원천: [피처 원천별 분류표](피처_원천별_분류표.md)

## 공통 설계

| 항목 | 내용 |
|---|---|
| 표본 | 주 분석 = PSG 확인이 끝난 59명. 민감도 = 측정 85명(PSG 확인 중 26명 포함). 85명 모두 규칙 개발 자료라 독립 검증군이 아님 |
| 결과 변수 | H1 = log(AHI+1), H2 = log(앙와위 AHI+1). 둘 다 주 가설(2026-11-16 사용자 결정). 보조: log ODI, LSaO2 |
| 기준 모델 B0 | 나이 + 성별 + BMI |
| 성능 지표 | 5겹 교차검증 50회 반복의 교차검증 R² 증가(ΔR²)와 범위(2.5~97.5 백분위), 50회 중 개선 비율, 중첩 F 검정 p, 조정 R² 증가 |
| 비교 방식 | 모델마다 값이 다 있는 같은 환자에서 1:1 비교 |
| 누출 방지 | PLS·EFA는 학습 fold 안에서 다시 적합 |
| 다중검정 | 사전 가설은 Bonferroni, 탐색은 BH-FDR |
| 판 | 현재 값(jung FH) / 최종표(yao4 FH, 등급 A~D) / 최종표 A·B만 |
| 최종 확정 모델 | **B0 + 최종 ANB + Pog_Ba_ant** (+ SIZE_PC1은 후보) |
| 판정 기준 (A 단계 이후) | 후보 선별: 기존 인자 위 p < 0.10, ΔR² > 0, 개선 ≥ 70%, 85명 같은 부호 / 확증: 사전 등록 + 다중검정 + 추가 환자 재확인 |

**표 읽는 법:** ΔR²는 별도 표기가 없으면 주 분석, 최종표 판, H1 / H2 순서다. "확정 위"는 B0 + 최종 ANB + Pog_Ba 위를 뜻한다.

## 종합

| 질문 | 답 |
|---|---|
| CBCT 자동 계측이 엑셀을 대체하나 | ANB는 그렇다(엑셀 이상). Nperp-Pog는 Pog_Ba로 대체. FH 지표(MP-FH·Nperp)는 FH 방향 오차로 재현 안 됨 |
| OSA 중증도와 관련된 골격 정보는 | **상악–하악 앞뒤 부조화 한 축**(ANB, Pog_Ba의 하악 성분). 두개저 위치·각도와 고전 비율은 더하지 않음(B 단계). 앙와위 AHI에서 더 강하다. 후보로 **구조 크기 축** |
| 기도 크기가 그 경로인가 | 아니다. 정적 CBCT 기도 크기는 ANB 위에 더하지 않고, 크기 축 효과를 매개하지도 않는다 |
| 3D 형태·연동·연조직이 더하는가 | 아니다. 모두 하악 후퇴 축이나 크기 축을 다시 잰 것이다. AMASSS 공동 축도 첫 축이 하악 후퇴, 둘째가 크기다(E) |
| 최종 모델 | B0 + 최종 ANB + Pog_Ba_ant. 크기 축은 검증 기각(V1). 수직 배치 지표는 유지 후보이며, 비앙와위 AHI와 관련(P 탐색) |
| 기존 인자 위에 더할 것 | 확증된 것은 없음. **수직 배치 지표 VERT_Z = 유지 후보**(새 환자에서 같은 방향 +0.08~0.09, 17명이라 미통과). 크기 축은 새 환자에서 반대 방향으로 기각. 2순위: 구인두 최소 단면적, 아래 앞얼굴 비율, ANB × 혀 위치. 지금까지 거론된 후보: 크기 축, 구인두 최소 단면적, ANB × 성별·혀 위치, 연구개 두께 (A 단계), 하악 길이·뒤 두개저 길이 (B 단계, 약), 하악 수직 형상 성분 (D-M5, 약), **아래 앞얼굴 비율 (D6)**. 수직 배치는 D-M5·D6·E(F1_PC4) 세 방법에서 반복 |
| 하악 후퇴의 기전 | ANB는 실제 계산한 앙와위 AHI를 강하게 설명(P2, 비앙와위는 약함). 다만 자세 의존 비 자체는 유의하지 않음(P1). 대리 지표로는 앙와위 의존성을 설명(A6) → 누운 자세에서 악화되는 구조적 소인. 비인두 공간이 좁을수록 앙와위 의존이 큼(D5, 후보) |
