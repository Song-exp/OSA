## 1. 연구 목표 한 줄 요약

OSA 환자 87명의 **CBCT(두개안면 영상)**와 **PSG(수면다원검사)**로 다음 두 가지를 합니다.

1. Roh et al. (2025, Eur J Orthod)의 "두개안면 골격 표현형과 OSA 중증도" 결과를 재현합니다.
2. CBCT에서 새로운 해부학적 인자를 찾습니다.

이를 위해 **CBCT에서 Roh의 계측값(ANB, MP-FH, TDI, 기도 부피 등)을 자동으로 측정하는 파이프라인**을 만들고, 기존 수작업 측정값(엑셀)과 비교해 검증하는 단계에 있습니다.

### 최근 발견: FH 평면 기울기 차이 (P_5 한 명)

| 변수 | 자동 | 엑셀 | 차이 |
|---|---|---|---|
| ANB (FH 무관) | 1.4° | 2.1° | −0.7° |
| Nperp-A | −6.7 mm | −2.5 mm | −4.2 mm |
| Nperp-Pog | −11.3 mm | −4.5 mm | −6.8 mm |
| MP-FH | 30.3° | 26.8° | +3.5° |

- FH를 기준으로 쓰는 변수 3개가 모두 **약 4° 기울어진 만큼** 어긋납니다.
- 그래서 우리 FH 평면(RPo, LPo, ROr)이 측정자의 FH와 다를 가능성이 높습니다.
- **한 명만 보고 기준을 고치지 않습니다.** 파일럿 12명 결과로 판단합니다 (계획 5장 C등급 절차).

## 3. 시작하기 (팀원 PC 설정)

### 3-1. 저장소에 없는 것 (따로 받아야 함)

환자 식별정보가 있어서 **git에 올리지 않습니다.** 데이터 관리 담당에게 받아 아래 위치에 둡니다.

```
Project/
├─ Data/CBCT/P_n_CBCT/*.dcm        CBCT DICOM (87명)
├─ Data/PSG/P_n_PSG_E 또는 _N/     PSG 원신호, 판독, 리포트 PDF
├─ Patient_Info_Data_87명_261019.xlsx
├─ Result/                         기존 MATLAB 결과 (검증용, 선택)
├─ *.pdf, *.pptx                   논문, 인수인계 자료
└─ docs/데이터_인수인계_정리.md     인수인계·미팅 정리 (git 제외)
```

### 3-2. 파이썬 환경 (Windows, Python 3.14)

```
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

- torch는 CUDA 12.8 빌드입니다(RTX 50 시리즈 기준). GPU가 다르면 `requirements.txt`의 torch 줄을 맞게 바꾸세요.
- 콘솔 한글이 깨지면 `set PYTHONIOENCODING=utf-8`을 실행합니다.

### 3-3. CBCT 자동 랜드마크 (선택, 약 5 GB)

`python/README.md`의 "CBCT 자동 랜드마크" 절을 따라 `third_party/`와 `models/`를 준비합니다. 두 폴더 모두 git에서 제외됩니다.
- `run_ali.py`는 한글 경로 문제(ITK) 때문에 `C:\Users\Public\osa_cbct`에 junction을 자동으로 만듭니다. junction은 연결 고리일 뿐이고 파일은 프로젝트 안에 있습니다.

## 6. 열린 문제

**데이터 담당 / 교수님께 물을 것** (답이 없어도 작업은 진행)
1. P_39 본인 CBCT 원본의 위치
2. 엑셀 CBCT 측정에 쓴 Invivo/Mimics 프로젝트 파일(랜드마크 좌표)이 남아 있는지
3. 측정자와 소프트웨어, 하악평면·TDI 측정점·PMCA 단면 방향의 정의
4. 엑셀 시트 이름이 "최종 102명"인데 87명만 있는 이유
5. 엑셀 Type 1~4의 정의, "구강 구조의 벡터 변화량"의 의미

**분석상 미결**
- PSG: 엑셀 값과 원신호가 다른 검사인 환자 11명이 있습니다. 어느 검사를 쓸지 정해야 합니다 (품질점검 4-D).
- PSG: Nox(N 그룹)의 판독층(자동/수동) 선택 규칙이 미완성이라, 11명은 이벤트 수가 리포트와 5% 넘게 다릅니다.
- 1차 재현의 통계 세부를 고쳐야 합니다.
  - 카이제곱 Yates 보정 여부, Bonferroni 방식
  - 중추성 무호흡 제외 기준이 적용되지 않음
- CBCT: 3절의 FH 기울기 문제가 남아 있습니다. 파일럿 결과로 판단합니다.
