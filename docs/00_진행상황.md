### 파일럿 자동 계측의 결론 (요약)

- 좌표계, 평면, 촬영 자세, 분할 마스크에는 문제가 없습니다.
  - 마스크는 CT 뼈 경계와 0.4 mm 이내로 일치합니다. **파일럿 환자 기준의 QC 근거일 뿐, 전체 환자의 분할 정확도를 검증한 것은 아닙니다.**
- **A·B·Pog·Me는 ALI 그대로 씁니다 (고정).** 윤곽 기반 보정 후보 4개는 모두 ALI보다 나빴습니다.
- ANB 오차(MAE 1.42°)는 대부분 P_32·P_41·P_69 세 명에서 나옵니다. 이들을 빼면 0.66°입니다.
- ALI의 Me는 뼈보다 약 1.5 mm 아래에 찍힙니다. 이것이 MP-FH가 약 +0.7° 치우친 이유를 설명합니다.
- 처음 P_5에서 본 "FH 4° 기울기"는 개인 단위 오차였고, 체계적인 문제는 아니었습니다.

2. **PSG:** 채널 7개씩 탭으로 나뉩니다. 탭마다 수면단계와 이벤트 색칠이 함께 나옵니다. 그림 아래 도구 막대(돋보기, 십자 화살표)로 확대하고 이동합니다.

   - 특정 구간만 보려면 "PSG 구간" 두 칸에 시작과 끝을 넣습니다 (예: `2013-08-15T22:51`, `2013-08-15T23:17`).
3. **CBCT 단면 탭:** 위쪽 슬라이더 3개로 축상·관상·시상 단면을 넘깁니다. "창 설정"에서 뼈 / 연조직 / 공기·기도 / 전체를 고릅니다.
4. **CBCT 3D 표면 탭:** [3D 표면 만들기]를 누르면 10~30초 뒤 뼈 표면(400 HU 이상)이 나옵니다. 마우스로 돌릴 수 있습니다.

| 화면의 정보 | 출처 |
|---|---|
| PSG 그래프 (신호, 수면단계, 이벤트) | **원본** (`Data/PSG`의 .ebm/.ndf와 판독 파일) |
| CBCT 단면, 3D 표면 | **원본** (`Data/CBCT`의 DICOM) |
| 왼쪽 "환자 요약" (나이, AHI, ANB 등) | **엑셀** (`Patient_Info_Data_87명_261019.xlsx`). 전문가 판독값과 수작업 계측값입니다. 원본에서 다시 계산한 값이 아닙니다 |

- PSG 원본을 읽는 데 수십 초가 걸립니다. 그동안에도 창은 멈추지 않습니다.
- P_34, P_40의 CBCT는 하위 폴더 문제로 아직 열리지 않습니다.
- 엑셀 파일이 없으면 환자 요약만 비어 있고, 그래프는 그대로 나옵니다.

**원본 데이터 불러오기** (`python/` 폴더에서 실행)

```python
from osa.psg_read import read_psg
from osa.psg_events import read_events
from osa.cbct import read_cbct

# PSG: 폴더 하나 = 환자 한 명의 원신호 (Embla/Nox 자동 판별)
rec = read_psg("../Data/PSG/P_1_PSG_E")
rec.channel_table                    # 채널 목록: 이름, 샘플링 주파수, 단위, 시작·끝 시각
ch = rec.channels[0]                 # ch.name, ch.data (numpy), ch.time (datetime64), ch.fs, ch.unit
events, stages, counts = read_events(rec)   # 호흡 이벤트, 30초 수면단계, 이벤트 종류별 개수

# CBCT: 폴더 하나 = DICOM 한 시리즈 (460장 → 3D 볼륨 하나)
d = read_cbct("../Data/CBCT/P_1_CBCT")
d.rescaled                           # float32 (행, 열, 슬라이스) = 512×512×460, HU 단위
d.voxel_size_mm                      # [0.39, 0.39, 0.39]
d.slice_table                        # 슬라이스별 환자 좌표(LPS mm)와 방향
```

- 채널 이름은 장비마다 다릅니다. `osa.naming.standard_names`로 SpO2, NasalPressure 같은 표준 이름으로 바꿀 수 있습니다.
- `read_cbct`는 하위 폴더까지 읽습니다. 그래서 하위 폴더에 다른 시리즈가 있는 **P_34, P_40은 지금 오류로 멈춥니다**. 상위 폴더만 읽는 옵션은 아직 추가하지 않았습니다.
- 원본 PSG를 파싱하면 1명에 수십 초가 걸립니다. 반복해서 쓸 때는 `python -m osa.batch psg|cbct`로 h5를 만들어 두고 `osa.batch.load_psg`/`load_cbct`로 읽는 편이 빠릅니다. 일괄 변환은 아직 하지 않았고, 변환 결과는 시험용 P_1, P_12뿐입니다. 전체 변환 시 PSG 약 85 GB, CBCT 약 15 GB입니다.

3. 측정자와 소프트웨어, 하악평면·TDI 측정점·PMCA 단면 방향의 정의
4. 엑셀 시트 이름이 "최종 102명"인데 87명만 있는 이유
5. 엑셀 Type 1~4의 정의, "구강 구조의 벡터 변화량"의 의미
6. P_65, P_67, P_69: 엑셀 PSG 값(AHI, RDI, ODI, LSaO2)이 같은 검사의 리포트와 다른 이유
7. P_32, P_41, P_69: 엑셀 ANB가 자동 계측과 3~4° 다른 이유 (측정 위치 또는 입력 오류)
8. 측정할 때 A·B를 단면에서 찍었는지, X-ray(투영) 모드에서 찍었는지
9. 엑셀 추가 변수의 정의와 판정 기준, NAV·PAV를 2022년 이후 측정하지 않은 이유, NCWR이 촬영 연도와 상관되는 이유 (`엑셀_CBCT_EDA_결과.md` 9장)

**분석상 미결**
- PSG: 엑셀 값과 원신호가 다른 검사인 환자 11명이 있습니다. 어느 검사를 쓸지 정해야 합니다 (품질점검 4-D).
