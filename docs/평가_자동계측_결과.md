  - P_78: 촬영 범위 확인용으로 따로 둔 환자입니다.

## 4. 확인 사항

- **Me 편향은 재현되지 않았습니다.** 파일럿에서는 MP-FH가 약 +0.7° 치우쳤는데, QC 통과 63명에서는 −0.76°입니다. 파일럿에서 본 Me 편향은 MP-FH 편향을 일관되게 설명하지 못합니다. 표본 차이로 봅니다.
- **ANB 오차가 3°를 넘는 환자는 5명입니다.**
  - P_37: Po 실패 환자입니다. 다만 ANB는 FH와 무관하므로 A·B 쪽 문제도 함께 의심됩니다.
  - P_31: 엑셀 −8.1°, 자동 0.0°. Class III로 분석에서 제외된 환자입니다.
  - P_67: 엑셀 PSG 값이 리포트와 다른 환자이기도 합니다.
  - P_8, P_43
  - 이 환자들은 P_32·P_41·P_69와 함께 검수 대상에 추가합니다.

## 5. 결론과 다음 단계

- **ANB는 자동 계측으로 쓸 만합니다.** MAE는 1.2°이고 분류 일치율은 80%입니다.
- **MP-FH와 Nperp는 Po 검출이 실패하면 크게 틀립니다.** 쓰기 전에 랜드마크 QC 표시가 필요합니다. 표시가 없는 환자에서는 MP-FH r이 0.87입니다.
- 실패한 Po를 고치는 방법(수동 수정 또는 다른 FH 구성)은 **방법 변경**에 해당합니다. 그래서 이번 평가와는 따로, 새 결정으로 다룹니다.
  - 고친 뒤의 수치는 이번 평가 결과와 섞지 않습니다.

## 6. M0 회귀: 엑셀 값 vs 자동 값 (같은 환자 집합)

- 코드는 `python/compare_m0_auto.py`, 결과는 `Result_py/eval/m0_auto_vs_excel.csv`입니다.
- **바꾼 것은 ANB와 MP-FH 두 개뿐**입니다. 나이, 성별, BMI, TDI, PMCA, PAL은 양쪽 모두 엑셀 값입니다.
- 대상은 주 분석 표본(Class III 제외) 중 자동 계측이 있는 80명입니다.
- 환자 제외는 **엑셀을 보지 않는 QC**로 했습니다. 엑셀과의 오차로 고르면 결과가 당연히 같아지는 순환 논리가 되기 때문입니다.

| 표본 | DV | N | adj R² 엑셀 → 자동 | ANB B (엑셀 → 자동) | MP-FH B (엑셀 → 자동) |
|---|---|---|---|---|---|
| Po 실패 5명 제외 | AHI | 75 | 0.187 → 0.166 | 1.50 → 1.89 | 0.51 → 0.03 |
| QC 표시 8명 제외 | AHI | 72 | 0.212 → 0.177 | 1.86 → 2.12 | 0.65 → 0.11 |
| QC 표시 8명 제외 | log(AHI+1) | 72 | 0.234 → 0.192 | 0.076 → 0.080 (둘 다 p<0.05) | 0.017 → −0.002 |
| (민감도) QC 제외 + ANB 오차 >3° 제외 | log(AHI+1) | 66 | 0.254 → 0.251 | 0.092 → 0.112 | 0.015 → −0.004 |

- **ANB의 효과는 보존됩니다.** 계수 크기, 방향, 유의성이 엑셀과 같거나 조금 더 큽니다.
- **MP-FH의 효과는 사라집니다.** 다만 엑셀 값으로도 원래 유의하지 않았습니다 (p 0.15~0.37).
  - MP-FH와 AHI의 단순 상관은 엑셀 −0.02, 자동 −0.15로 거의 0입니다.
  - M0에서 MP-FH 계수는 ANB와 나이를 보정한 뒤에야 나타나는 약한 효과입니다. 그래서 측정값이 조금만 달라져도 흔들립니다.
- **adj R²는 0.02~0.04 낮아집니다.**
  - ANB 오차가 3°를 넘는 환자를 뺀 민감도 분석에서는 차이가 거의 없습니다 (0.254 → 0.251).
  - 즉 adj R²가 떨어진 것은 주로 ANB 큰 오차 환자들 때문입니다.

## 7. 이상 환자 진단: 시작점(랜드마크)이 원인인가

- 코드는 `python/landmark_outlier.py`, 결과는 `Result_py/eval/landmark_outlier*.csv`입니다.
- **방법**
  - 머리 좌표계를 쓰지 않습니다. 정상 환자 58명의 랜드마크 16개로 평균 배치를 만듭니다.
  - 각 점을 하나씩 빼고 나머지로 정렬한 뒤, 뺀 점이 평균 위치에서 얼마나 벗어났는지 잽니다.
  - 정상 범위는 정상 환자들의 99백분위로 정했습니다 (점마다 6~15 mm).
  - 범위를 넘은 점은 평균 배치로 예측한 위치로 바꾸고 다시 계산했습니다.
- **한계:** 정상 범위가 수 mm이므로 **약 7 mm 이상의 큰 실패만 잡힙니다.** ANB 3~4° 차이는 A나 B가 3~4 mm만 움직여도 생기므로 이 방법으로는 구분할 수 없습니다.

| 분류 | 환자 | 결과 |
|---|---|---|
| **Po 실패 확정, 고치면 엑셀과 맞음** | P_16, P_35, P_37 | MP-FH: P_16 11.5 → 23.9 (엑셀 22.8), P_35 6.8 → 30.4 (28.0), P_37 −49.8 → 29.9 (33.9). P_37의 ANB도 0.9 → 8.5 (8.6)로 맞음. ANB도 Po로 만든 정중면에 투영하기 때문 |
| Po 이탈이 있지만 결과에 영향 거의 없음 | P_23 | RPo가 25 mm 벗어났는데도 MP-FH는 엑셀과 같음 (34.1 vs 34.0) |
| 여러 점이 함께 불안정 | P_20, P_85, P_86 | 점 하나로 설명되지 않아 영상을 직접 봐야 함 |
| **ANB가 크게 다른데 A·B는 정상 범위** | P_8, P_31, P_32, P_41, P_43, P_67, P_69 | 큰 랜드마크 실패는 아님. 남는 원인은 A·B의 작은 위치 차이, 정의 차이(단면 vs 투영), 엑셀 쪽 문제. 영상을 직접 봐야 구분됨 |
| MP-FH가 6~9° 다른데 점은 정상 범위 | P_2, P_4, P_13, P_61, P_64, P_76 | 자동 값이 대부분 낮음. 하악평면 정의 차이일 가능성 (교수님께 물을 질문 3번) |
| Pog–Me 표시 | P_10, P_12, P_27 | P_27은 Pog가 정상 범위 경계(9 mm). 계측 오차는 크지 않음 |

## 8. 종합

- 남은 문제는 크게 둘입니다.
  - **Po 큰 실패**는 원인이 분명하고, 점 하나만 고치면 해결됩니다.
  - **ANB 3° 이상 차이 7명과 MP-FH 정의 차이로 보이는 6명**은 랜드마크가 크게 틀린 것이 아니어서, 영상을 직접 봐야 원인을 가릴 수 있습니다.
- 회귀 관점에서는 ANB 효과가 보존됩니다. MP-FH는 엑셀로도 원래 불안정한 변수입니다.
