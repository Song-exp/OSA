## 4-0. 목적

- 하악·두개저 모양 전체를 환자끼리 비교할 수 있는 같은 형식의 좌표 묶음으로 만듭니다.
- 이 좌표 묶음은 다음 단계(PCA)의 입력입니다. 그래서 이번 단계의 핵심은 **입력 품질 확인**입니다.
- 대응점과 템플릿은 결과변수(PSG)를 전혀 쓰지 않으므로, 전체 환자로 한 번 만듭니다.

## 4-1. 표면 만들기

| 단계 | 방법 |
|---|---|
| 입력 | AMASSS 구조 마스크 (2단계) |
| 조각 제거 | 연결된 덩어리 중 **가장 큰 것만** 사용 (턱받침·설골 같은 떨어진 조각 제외) |
| 표면 | marching cubes (간격 2복셀) → 환자 좌표(LPS, mm)의 표면 점 |

- 마스크의 떨어진 조각은 형태에 들어가지 않습니다. 그래서 3단계의 두개저 조각화 9명(예: P_51의 잘린 후두골 조각)은 표면에 영향이 없습니다. 다만 가장 큰 덩어리 자체가 덜 잡혔는지는 따로 봐야 합니다.
- 알려진 한계: **하악 마스크에 치아가 포함됩니다.** 치아 결손이나 보철이 형태 차이로 섞일 수 있습니다.

## 4-2. 대응점 만들기

환자마다 표면 점의 개수와 순서가 달라서 그대로는 비교할 수 없습니다. 그래서 모든 환자에서 같은 번호의 점이 같은 위치를 가리키도록 맞춥니다.

| 단계 | 방법 |
|---|---|
| 템플릿 | 크기가 중앙값인 환자 1명 (하악 P_34, 두개저 P_49)의 표면에서 점 2,048개를 무작위로 뽑음 |
| 정합 1 | 템플릿을 환자 표면(점 5,000개 표본)에 맞춤: 회전·이동·크기 (CPD 강체 + 크기) |
| 정합 2 | 모양을 휘어 맞춤 (CPD 비강체, α=2, β=8 mm, 80회 반복) |
| 대응점 | 정합된 템플릿의 각 점에서 **가장 가까운 환자 표면 점** → 환자의 i번 점 |

- 결과는 환자마다 2,048 × 3 좌표입니다 (`points.npz`). 모든 점은 실제 환자 표면 위에 있습니다.
- 환자별 계산 결과는 바로 캐시에 저장합니다. 작업이 멈추면 같은 명령으로 이어서 실행할 수 있고, 한 구조당 83명에 약 80분 걸립니다.
- 그림 `4-2_*_대응점_예시.png`: 템플릿과 정합 잔차가 작은·중간·큰 환자 3명. 같은 색이 같은 번호의 점입니다. 색 배치가 환자 사이에서 유지되면 대응이 맞는 것입니다.

## 4-3. 시행착오: 정합 시작 자세 (10/28)

| | 처음 | 수정 후 |
|---|---|---|
| 시작 자세 | FH 머리 좌표계 (ALI Po 사용) | **Po를 쓰지 않는 정중면 좌표계** (원점 N, 좌우 = N·S·Ba·ANS·PNS의 최소제곱 평면 법선, 앞 = PNS→ANS) |
| 문제 | Po 검출이 실패한 환자(P_37)에서 정합이 엉뚱한 곳에 멈춤 (잔차 7.5 mm) | P_37 잔차 0.6 mm |
| 절차 | | 5명으로 개선을 먼저 확인한 뒤 83명 전원을 다시 실행 |

- 좌표계 자가 점검(`shape_ssm.py --selftest`)을 통과했습니다. 머리를 임의로 돌리고 옮겨도 좌표가 같게 나옵니다.
- 처음 실행한 결과(15명)는 `shape/_archive_MAND_15pilot_20261028/`에 보관했습니다.

## 4-4. 정렬 (두 가지 버전)

| 버전 | 방법 | 남는 정보 | 주의 |
|---|---|---|---|
| frame | 같은 대응점을 머리 좌표계(Jung FH·MSP, 원점 N)로 옮김 | 크기, 위치, 모양 | FH가 ALI Po에 의존 → Po 실패 5명(P_16, 20, 23, 35, 37)은 확정 실패로 분리 |
| procrustes | 일반화 Procrustes(GPA): 이동·회전·크기를 제거 | 순수한 모양 (크기는 중심 크기로 따로 저장) | Po와 무관 |

- **GPA 수정 (10/28):** 평균 형태를 주 분석 환자로만 만들고, 확정 실패 환자는 그 평균에 한 번 정렬만 하도록 고쳤습니다 (`ssm_review.gpa_main`).
  - 이렇게 하면 실패 환자가 평균 형태를 오염시키지 않습니다.
  - 지금은 procrustes 버전에 확정 실패가 0명이라 결과가 이전과 같습니다. 점검 스크립트로 같은지 확인했습니다.

## 4-5. 대응점 품질 QC (83명)

지표 두 가지를 따로 관리합니다. 기준을 넘으면 검수 대상으로 표시만 하고, 제외하지 않습니다.

| 지표 | 의미 | 검수 표시 기준 |
|---|---|---|
| 정합 잔차 | 정합된 템플릿 점이 환자 표면에 얼마나 가까운가 (표면이 잘 맞았나) | 평균 잔차 > 중앙값 × 3 |
| 랜드마크 전달 오차 | 템플릿의 랜드마크 위치에 해당하는 대응점이 그 환자의 ALI 랜드마크와 얼마나 떨어졌나 (같은 해부학적 위치를 가리키나) | 로버스트 z > 3.5 |
| 중복 없음 비율 | 서로 다른 템플릿 점이 같은 환자 점에 몰리지 않았나 | 표시 기준 없음 (참고) |

- 잔차가 작아도 점이 표면을 따라 미끄러질 수 있습니다. 그래서 전달 오차를 따로 봅니다.
- 전달 오차에는 템플릿 점 간격만큼의 오차가 포함됩니다. 그래서 절대값보다 **환자 간 비교용**입니다.

**하악 (템플릿 P_34)**

| 지표 | 중앙값 | 5~95백분위 | 최대 |
|---|---|---|---|
| 정합 잔차 평균 | **0.51 mm** | 0.46~0.71 | 1.31 (P_20) |
| 정합 잔차 95백분위 | 1.08 mm | 0.94~1.70 | 2.58 (P_20) |
| 중복 없음 비율 | 0.98 | 0.97~0.99 | 최소 0.95 |
| 전달 오차 (환자별 중앙값) | 3.2 mm | 1.9~6.0 | 6.7 (P_7) |
| 점별 전달 오차 중앙값 | Me 3.0, Pog 3.1, B 3.2, Gn 2.7, RGo 3.9, LGo 2.7 mm | | RGo 95백분위 10.7 (Go는 곡면 위 점이라 원래 모호) |

- 잔차 3배 초과: 0명
- 전달 오차 표시: P_20(B, RGo), P_53(B), P_77(B)
- 메모: P_7은 Me·Pog 전달 오차가 약 10 mm인데 정합 잔차는 정상입니다.

**두개저 (템플릿 P_49)**

| 지표 | 중앙값 | 5~95백분위 | 최대 |
|---|---|---|---|
| 정합 잔차 평균 | **1.41 mm** (하악의 약 3배) | 1.17~2.49 | 3.03 (P_50) |
| 정합 잔차 95백분위 | 3.82 mm | 3.01~13.91 | 21.6 (P_50) |
| 중복 없음 비율 | 0.97 | 0.93~0.98 | 최소 0.92 |
| 전달 오차 (환자별 중앙값) | 5.4 mm | 3.9~7.4 | 8.7 (P_56) |
| 점별 전달 오차 중앙값 | S 5.3, Ba 5.0, N 7.0 mm | | |

- 잔차 3배 초과: 0명
- 전달 오차 표시: S가 P_7, 12, 18, 42, 69 / 환자별 중앙값이 P_56
- 잔차 95백분위의 꼬리가 깁니다. 일부 환자에서 표면 일부가 크게 안 맞는다는 뜻입니다. 최대인 P_50은 촬영 범위가 다른 환자입니다 (3단계).

## 4-6. 대응점 점검 사례 (판정 전, 잠정)

`ssm_corr_check.py`는 전달 오차가 큰 사례를 그립니다. 각 사례마다 전달 오차가 중앙값인 환자를 비교용으로 함께 그립니다.
- 빨간 점은 대응점, 파란 X는 ALI 랜드마크입니다.
- 빨간 점이 맞는 자리에 있고 파란 X가 벗어났으면 ALI 오류, 반대면 대응점이 미끄러진 것입니다.
- 판정은 사람이 합니다.

| 사례 | 보이는 것 | 잠정 해석 |
|---|---|---|
| 하악 P_7 Me·Pog | ALI 점이 뼈 윤곽 밖 (턱받침 근처) | ALI 오류 가능성 |
| 하악 P_53·P_77 B | 오목한 부위에서 위아래 위치가 다름 | B점 정의 자체의 모호함. 원본 확인 필요 |
| 하악 P_20 B·RGo | Po 실패로 머리 좌표계가 기울어 있음 | 좌표계 문제 (그림이 머리 좌표계 기준이라 기울어 보임) |
| 두개저 S (5명) | S는 안장 안쪽 빈 공간의 중심점 | **지표의 한계.** S는 뼈 표면 위의 점이 아니라서 표면 대응점과 원래 떨어짐. 정합 실패의 근거로 쓰지 않음 |
| 두개저 P_56 N·S | 여러 점이 함께 큼 | 원본 확인 필요 |

그림: `4-6_*_대응점_점검_사례.png`

## 4-7. 확정 실패 (`ssm_review.py`의 `CONFIRMED`)

- 근거가 확인된 환자만 사람이 적습니다. 확정 실패는 PCA 축 계산과 주 분석에서 빠지고, 점수는 진단용 투영값으로만 남습니다.
- **지금 적힌 것은 frame 버전의 Po 실패 5명뿐입니다** (하악·두개저 공통). procrustes 버전의 확정 실패는 0명입니다.
- 검수 표시만 있고 확정되지 않은 환자는 주 분석에 남습니다.

## 4단계에서 안 한 것 (PCA 전에 할 일)

1. **검수 확정:** 대응점 점검 사례(P_7, P_53, P_77, P_20, P_56)와 3단계 검수 대상 29명을 육안으로 판정하고 `CONFIRMED`에 기록합니다.
2. **두개저 정합 방법:** 지금 방법을 그대로 쓸지(품질 한계로 보고), 정합 방법을 바꿔 다시 돌릴지(약 80분) 정해야 합니다.

4. **치아 분리:** 하악 마스크에서 치아를 빼는 방법(DentalSegmentator 등)을 검토합니다.
5. 상악·상기도는 아직 대응점을 만들지 않았습니다.
