# CBCT 원본에서 Roh (2025) 변수 측정 계획

> 작성일: 2026-10-24 (같은 날 검증 체계 반영해 수정)
> **목표:** 기존 전문가 계측법을 CBCT 원본에서 재현하는 자동 계측 파이프라인을 만들고, 그 신뢰도를 정량적으로 검증합니다. 측정 성능이 확인된 변수만 Roh 재현과 새 인자 발굴에 씁니다.
> - **측정 정의:** Roh 그림 1이 최우선입니다. 그림에 없는 세부 사항은 참고 논문에서 가져옵니다. 정의는 엑셀을 보기 전에 문서로 고정합니다 (5장).
> - **검증:** 엑셀 값은 측정자가 직접 찍은 랜드마크로 계산한 값이므로, **엑셀과의 대조를 전문가 측정과의 비교로 봅니다**. 외부 자문 없이 데이터 안에서 기준을 세웁니다 (7장).
>   - 계측값: 평가용 환자에서 엑셀과 일치도 확인
>   - 랜드마크: 좌표 원본이 없으므로 세 가지로 대신합니다
>     - 랜드마크를 공유하는 변수들의 동시 일치
>     - 해부학적 타당성 자동 점검
>     - 직접 눈으로 검수
> - 엑셀은 **정의가 제대로 구현됐는지 확인하는 용도**입니다. 엑셀에 가장 잘 맞는 계산법을 정답으로 고르지 않습니다.
> - 원본 결측과 제외 대상(P_39, P_50, P_78 등)은 `원본데이터_결측_점검.md`에 정리했습니다.

## 1. 전체 흐름

**연구 단계**

| 단계 | 할 일 | 결과물 |
|---|---|---|
| 1 | (가능하면) 원 측정자의 프로젝트·좌표 파일 확보. 없어도 진행 | 원래 측정 기준 확인 |
| 2 | Roh와 보조 논문으로 정의를 고정하고 근거 등급 부여 (5장) | 변수별 계측 프로토콜 |
| 3 | 파일럿 환자 선정, 직접 랜드마크 검수 | 파일럿 랜드마크 세트 |
| 4 | 파일럿에서 자동 추출법을 개발하고 엑셀과의 오차 분석 | 고정된 측정 파이프라인 |

```
A. 볼륨 불러오기 (완료)
B. 머리 기준 좌표계 만들기 ── FH 평면, 정중시상면(MSP), 관상면
C. 랜드마크 지정 ─────────── 3장의 점들 (자동 + 사람 검수)
D. 계측 ──────────────────── 각도·거리 (MSP 투영), 관상 단면 폭, 기도 분할
```

## 2. B. 머리 기준 좌표계

Jung 2025에 나온 Invivo 기준 좌표계(AFOR)를 기본으로 씁니다. Roh와 같은 소프트웨어라 같은 방식이었을 가능성이 가장 높습니다.

| 평면 | 정의 (Jung 2025) | 대안 (Dot 2022) |
|---|---|---|
| **수평면 (FH)** | 우측 Porion, 좌측 Porion, 우측 Orbitale | 좌측 Orbitale, 우측·좌측 Porion |
| **정중시상면 (MSP)** | FH에 수직이고 Nasion과 Basion을 지나는 평면 | — |
| 관상면 | 두 평면에 수직이고 Nasion을 지나는 평면 | — |

- 구현: 세 평면으로 회전 행렬을 만들고 볼륨을 다시 표본화합니다(앞서 시연한 단면 자르기와 같은 기술).
- 위험: Dot 2022에 따르면 Or과 Po는 사람이 찍어도 재현성이 낮습니다(2 mm 이상). 그래서 FH 기준 각도(MP-FH)와 Nperp 거리가 가장 흔들리기 쉬운 변수입니다.

## 4. D. 계측 정의

### 4-1. 각도·거리 (그림 1A)

그림 1A는 측면 투영 화면(X-ray 모드)에서 그렸습니다. Jung도 "모든 각도는 정중시상면에 투영해 계산"한다고 했으므로 **MSP 투영 2D 계산을 기본으로** 하고, 3D 공간각을 대안으로 계산해 비교합니다.

| 변수 | 계산 | 확정해야 할 것 |
|---|---|---|
| ANB | N에서 A와 B로 그은 두 선의 각도 | 2D 투영각 vs 3D 공간각 |
| Nperp-A / Nperp-Pog | N을 지나 FH에 수직인 선(Nperp)에서 A / Pog까지의 거리. 앞쪽이 + | 부호 방향 (엑셀 값은 −8~+7) |
| **MP-FH** | 하악평면과 FH의 각도 | **하악평면 정의.** 그림 1A는 하악 아래 경계의 접선처럼 보임. 후보: ① Go–Me 직선, ② Me를 지나는 하악 하연 접선, ③ Me·Go-L·Go-R 3D 평면 |
| PAL | PNS–Eb 직선 거리 (그림 1D) | 3D 거리 vs MSP 투영 |

### 4-2. 관상 단면 폭 (그림 1B, PPT 11)

- 제1대구치 **저항중심 높이를 지나는 관상 단면**(FH와 MSP에 수직) 한 장에서 측정합니다.

| 변수 | 계산 | 확정해야 할 것 |
|---|---|---|
| MxAW / MnAW | 좌우 상악·하악 치조골 바깥 피질 사이 거리 (그림 1B의 빨간 점) | 점을 찍는 높이와 위치. 문헌마다 다름 (치조정, 저항중심 높이 등) |
| **TDI** | MxAW − MnAW | 위에 따라 결정됨. 후보 비교는 파일럿 환자로만 (5장 C등급 절차) |
| PHI | 구개 높이(PH) ÷ 상악 교합폭(MxOW) × 100 | MxOW 기준점(교두 vs 치아 구개측) |
| NCWR | 비강 최대폭(NCW) ÷ 상악 기저폭(MxBW) × 100 | MxBW 높이 |

- 저항중심 위치는 치근 길이의 1/3~1/2(분지부 근처)로 근사합니다. 문헌 정의를 먼저 찾고, 없으면 C등급 절차를 따릅니다.

### 4-3. 기도 (그림 1C·1D, PPT 12)

| 변수 | 경계 (Roh) | 계산 |
|---|---|---|
| **NAV** | 위: Na–Ba 평면 / 아래: 구개평면(ANS–PNS) / 뒤: Se–PNS 평면 / 앞: Rh–ANS 평면 / 부비동 제거 | 경계 안쪽 공기 voxel 수 × voxel 부피 |
| **PAV** | 위: Se–PNS 평면 / 아래: Eb를 지나 FH에 평행한 평면 / 옆: 인두벽 | 같음 |
| **PMCA** | PAV 마스크 안 | 단면마다 넓이를 재서 최솟값. **단면 방향 확정 필요** (FH에 평행한 축상 vs 기도 중심선에 수직) |

- **임계값:** 논문은 NAV −400~−500, PAV −1200~−400 HU입니다. 우리 영상 값은 −1024~3071이라 HU와 비슷한 척도로 보입니다.
  - 먼저 기도 안 공기가 실제로 약 −1000인지 확인합니다.
  - 그다음 논문 임계값을 그대로 적용합니다. 임계값은 논문에 명시돼 있으므로(A등급) 엑셀에 맞춰 바꾸지 않습니다. 엑셀 NAV(57명), PAV(25명)와 크게 어긋나면 분할 경계 쪽을 먼저 봅니다.
- **부비동 제거:** NAV에서 가장 까다로운 단계입니다. 연결 영역 분석에 형태 연산(침식, 팽창)을 더해 상악동과의 좁은 연결을 끊습니다.
- 공기가 바깥과 이어져 있어서 경계 평면으로 먼저 자른 뒤에 연결 영역을 구해야 합니다. 앞서 P_1 시연에서 확인한 내용입니다.

### 4-4. 엑셀 추가 변수 (2차 우선순위)

| 변수 | 기준 (PPT 13~14) |
|---|---|
| Septal deviation | MSP에서 비중격이 가장 많이 휜 점(SDp)까지 거리 > 2 mm면 1 |
| Nasal floor cant | 좌우 비강저 최하점(NfR, NfL)을 이은 선과 MSP의 각도가 90°에서 ±2° 넘게 벗어나면 1 |
| Occlusal plane | 좌우 상악 제1대구치 근심협측 교두정 + 앞니 겹침 중간점, 3점으로 만든 평면 |
| Nasal obstruction, Maxillary sinusitis | 임상 소견이라 측정 대상 아님 |

## 5. 정의 근거 등급 (엑셀을 보기 전에 고정)

변수마다 **측정 정의가 논문에 얼마나 명확히 규정돼 있는지**를 등급으로 매깁니다.

- **A** 논문 정의를 그대로 사용
- **B** 논문이 모호해서 선행연구 정의를 채택
- **C** 정의가 불명확해서 후보 중 경험적으로 선택

**근거 등급과 검증 상태는 별개입니다.** A등급이어도 자동 측정 정확도가 나쁠 수 있습니다. C등급 정의가 엑셀과 잘 맞아도 원 측정법을 복원했다는 뜻은 아닙니다. 두 가지를 따로 기록합니다.

| 항목 | 등급 (확정) | 근거 / 남은 문제 |
|---|---|---|
| 머리 좌표계 (FH, MSP) | B | Roh는 "head reorientation process"라고만 적음 → Jung 2025의 Invivo 좌표계 |
| ANB, Nperp-A, Nperp-Pog | A | 표 1, 그림 1A. 2D 투영 여부는 B (Jung) |
| MP-FH | **C** | 표 1은 "Mandibular plane angle to FH"뿐이고 인용 없음. 후보 3개 (4-1) |
| PAL | A | 표 1: "PNS에서 Eb까지, 정중시상 단면에서" |
| **TDI 단면 높이** | **B** | 본문: "제1대구치 저항중심 높이의 관상 단면". 저항중심 = **다근치는 분지부(furcation)** (Koo 2017, Smith & Burstone 1984) |
| **TDI 측정점 (MxAW, MnAW)** | **C** | 후보 2개. ① 좌우 저항중심에서 수평으로 나간 **협측 피질골 바깥면** 사이 거리 (Roh 용어 "alveolar width"와 그림 1B 빨간 점에 맞음 → 주 후보) ② 좌우 저항중심 사이 거리 (Koo 2017의 basal arch width) |
| PHI, NCWR | C | 표 1에 비율 정의만 있음. MxOW 기준점, NCW·MxBW 높이 불명확 |
| NAV, PAV 경계·임계값 | A | 표 1, 본문 (경계 평면 6개, NAV −400~−500, PAV −1200~−400 HU). 단 **Se는 정의가 없어 C** (Sella로 가정) |
| 부비동 제거 | B | 3-Matic에서 수동 제거라고만 적음 → 형태 연산 |
| PMCA | **C** | "Invivo가 인두 마스크 안에서 자동 산출"이라고만 적음. 단면 방향 후보 2개 (FH 평행 축상, 기도 중심선 수직) |

**문헌 확인 결과 (2026-10-24)**
- **Roh 본문에는 측정법 인용 문헌이 하나도 없습니다.** 정의의 근거는 표 1, 그림 1, 본문 몇 문장뿐입니다. 본문의 인용 [11, 24]는 표본 수 계산용입니다.
- 같은 연구그룹의 선행 논문인 Kim 2020 (PLoS One, Roh 참고문헌 26)을 확인했습니다. 이 논문은 2D 측면 두부계측이라서 CBCT 정의가 없습니다. 하악평면 정의도 없습니다.
- TDI의 "저항중심 높이"는 Koo 2017 (Korean J Orthod 47:167)의 방법과 같습니다. 이 방법에서 저항중심은 단근치는 치근 치관측 1/3, 다근치는 분지부입니다. Zhang 2024 (Heliyon)도 같은 방법을 썼고, 상악−하악 폭 차이의 정상 범위를 −2~2 mm로 보고했습니다. Roh의 nonTSD 기준(> −2 mm)과 맞습니다.
- 확인하지 못한 문헌: Hwang 2018 (AJODO 154:365, 협측 피질골 투영법). 원문을 구하면 TDI 측정점 후보 ①의 세부 정의를 B로 올릴 수 있습니다.

**C등급 처리 절차**
1. 후보를 미리 문서에 적습니다.
2. **파일럿 환자로만** 모든 후보의 일치도를 계산하고, 1등만이 아니라 전체 결과를 기록합니다.
3. 일치도와 함께 해부학적 타당성(7-3의 점검)을 보고 고릅니다.
4. 결과에는 "원 측정법과 같다고 확인된 방법"이 아니라 **"경험적으로 선택한 방법"**으로 적습니다.

## 6. C 단계: 랜드마크를 얻는 방법

| 방법 | 장점 | 단점 |
|---|---|---|
| 수작업 (3D Slicer Markups) | 정확도를 통제할 수 있음 | 1인당 15~20분(점 20개 이상), 해부학 숙련 필요 |
| 자동 (사전학습 모델, 예: SlicerAutomatedDentalTools의 ALI-CBCT) | 빠름 | **Se, Rh, Eb, 치조폭 점은 지원하지 않을 가능성이 높음.** 이 장비와 0.39 mm 해상도에서 검증 필요 |
| **혼합 (추천)** | 자동으로 찍고 사람이 검수·수정. 지원하지 않는 점만 수작업 | 도구 설치와 검수 화면이 필요 |

- **ALI-CBCT 지원 랜드마크 (2026-10-24 확인, 모듈 소스 기준)**
  - 있음: Ba, S, N, RPo/LPo, ROr/LOr, ANS, PNS, A, B, Pog, Gn, Me, RGo/LGo, RCo/LCo, 제1대구치 교두·치근점(UR6/UL6/LR6/LL6), C2~C4
  - 없음 (수작업): Rh, Eb, MxAW·MnAW 피질골 점, 대구치 분지부(저항중심), 비강·구개 폭 점
  - 검증 성적: 32개 점 평균 1.54 ± 0.87 mm (Gillot 2023). 학습 데이터는 0.3~0.4 mm 대형 FOV 77건으로, 우리 영상(0.39 mm)과 비슷합니다
- **Slicer 없이 실행한 ALI 코드 검증 (P_5)**
  - 확인한 것
    - 모델 가중치가 오류 없이 로드됨 (MONAI 1.6 네트워크 구조가 학습 당시와 같음)
    - 4회 반복 실행에서 15개 점 좌표가 완전히 같음 (시작점은 무작위지만 결과는 같은 점으로 수렴)
    - 좌표계 변환(LPS)이 맞음 (그림에서 점이 해부학적 위치에 찍힘)
    - 해부학 점검 통과
  - 확인하지 못한 것
    - Slicer 안에서 돌린 결과와 같은지 (Slicer 기준 출력이 공개돼 있지 않음)
    - 우리 데이터에서의 정확도 (파일럿에서 엑셀과 대조)
  - 최신 Slicer 확장은 MONAI 1.3.2를 쓰고, 독립 실행 저장소는 torch 1.10이라 RTX 5060(최신 GPU)에서 돌지 않습니다. 그래서 **Slicer 확장 경로로 진행합니다**
- 참고: Jung 2025의 Invivo 자동 랜드마크는 평균 오차가 약 1 mm였고, Porion, Gonion, Stomion은 2 mm를 넘었습니다. 측정값 오차는 각도 약 0.9°, 거리 약 1.3 mm였습니다.

## 7. 검증 방법

### 7-1. 검증의 기준: 엑셀 = 전문가 측정

- 엑셀 값은 측정자가 직접 찍은 랜드마크로 계산한 결과입니다. 그래서 **엑셀과의 대조를 전문가 측정과의 비교로 봅니다.**
- 빠진 것은 좌표 원본뿐입니다. 계측값 하나만 맞으면 다른 좌표 조합이 우연히 같은 값을 냈을 수 있습니다. 그래서 랜드마크는 7-3의 방법으로 따로 확인합니다.
- 외부 전문가 자문은 받지 않습니다. 필요해지면 나중에 선택적으로 추가합니다. 예를 들어 결과를 방법론 논문으로 낼 때입니다.

### 7-2. 변수 유형별 검증 항목

| 변수 | 엑셀 대조 | 추가 점검 |
|---|---|---|
| ANB, Nperp, MP-FH, TDI, PHI, NCWR | 계측값 오차 | 공유 랜드마크 일관성 (7-3) |
| PAL | 길이 오차 | PNS, Eb 위치 검수 |
| PMCA | 면적 오차 | 분할 마스크와 최소 단면 위치를 눈으로 검수 |
| NAV, PAV | 부피 오차 (NAV 57명, PAV 25명만 가능) | 분할 경계 검수, 부비동·구강 누출 확인 |

### 7-3. 좌표 원본 없이 랜드마크를 확인하는 방법

1. **공유 랜드마크 동시 일치.** 한 랜드마크를 쓰는 변수들이 모두 엑셀과 맞으면, 그 랜드마크가 일관되게 잡혔다고 봅니다.

   | 랜드마크 | 함께 쓰는 엑셀 변수 |
   |---|---|
   | N | ANB, Nperp-A, Nperp-Pog |
   | A | ANB, Nperp-A |
   | FH (Po, Or) | MP-FH, Nperp-A, Nperp-Pog |
   | PNS | PAL, NAV, PAV |
   | 대구치 단면 | TDI, PHI, NCWR |

   - 변수 중 하나만 크게 어긋나면 그 변수에만 쓰이는 점이나 정의를 의심합니다. 예를 들어 MP-FH만 어긋나면 Go, Me나 하악평면 정의를 봅니다.
2. **해부학적 타당성 자동 점검** (모든 환자)
   - 좌우 대칭점(Po, Or, Go)이 MSP 기준으로 대칭인가
   - 점 사이 거리가 정상 범위인가 (예: N–Me, ANS–PNS)
   - 점이 뼈 표면 위에 있는가 (주변 HU 값)
   - 기준을 벗어난 환자는 표시하고 검수합니다.
3. **직접 검수.** Jung 2025 표 1의 정의로 화면에서 확인합니다.
   - 파일럿은 전원 검수합니다.
   - 평가 환자는 2번에서 걸린 환자만 검수합니다.
   - 파일럿 일부는 2주 뒤 다시 찍어 측정자 내 신뢰도를 구합니다.
4. **자동 랜드마크 도구의 기존 검증 활용.** ALI-CBCT 같은 도구는 전문가 좌표로 학습·검증된 모델입니다. 그 결과를 인용하고, 우리 장비에서도 맞는지는 1~3번으로 확인합니다.

- 좌표 오차가 계측값에 주는 영향은 랜드마크를 1~2 mm 흔들어 계측값이 얼마나 변하는지로 계산합니다(민감도). 영향이 큰 점은 검수를 더 엄격히 합니다. 예를 들어 TDI의 치조폭 점이 그렇습니다.

### 7-4. 계측값 지표와 잠정 목표

- 지표: 평균 차이(치우침), MAE, ICC, Bland–Altman, 큰 오차가 난 환자 목록
- 아래 목표는 임상 허용오차가 아니라 개발용 잠정치입니다. 원 측정자의 반복측정 오차와 영상 해상도(0.39 mm)를 확인한 뒤 확정합니다.

| 변수 | 잠정 목표 | 주로 볼 원인 |
|---|---|---|
| ANB | MAE 1° 이내 | N, A, B 위치, MSP |
| MP-FH | MAE 1° 이내 | FH, 하악평면 정의 |
| TDI | MAE 1 mm 이내 | 대구치 단면, 치조폭 측정점 |
| PAL | MAE 1~2 mm | PNS, Eb |
| PMCA | 상대오차와 절대오차를 함께 | 분할, 단면 방향 |
| NAV, PAV | 상대오차 10% 이내 (탐색적) | 분할 범위, 임계값 |

### 7-5. 분류 일치도는 따로 보고합니다

- ANB 4°, MP-FH 25°/30°, TDI −2.5 mm 기준선 근처에서는 작은 오차로도 분류가 바뀝니다.
- 엑셀 값 기준 분류와 자동 측정값 기준 분류를 비교합니다. 보고 항목은 일치율, κ, 기준선 ±오차 범위 안에 있는 환자 수입니다.
- **TDI −2.5~−2 mm 경계 구간**은 Roh 기준대로 TSD와 nonTSD 어느 쪽에도 넣지 않습니다.

### 7-6. 개발용과 평가용 환자 분리

자문이 없으므로 **이 분리가 엑셀에 과하게 맞추는 것을 막는 핵심 장치**입니다.

| 세트 | 인원 | 용도 |
|---|---|---|
| **파일럿 (개발)** | 10~15명 | 정의 확정, C등급 후보 비교, 파이프라인 조정 |
| **평가** | 나머지 (약 70명) | 고정된 파이프라인으로 한 번만 평가 |

- **평가 결과를 보고 파이프라인을 다시 고치면 그 결과는 더 이상 독립 검증이 아닙니다.** 고치게 되면 고친 내역을 기록하고, 해당 결과를 "개발 후 재평가"로 따로 표시합니다.
- 파일럿과 평가 환자는 측정 전에 무작위로 나누고 목록을 저장합니다.
- **파일럿 선정 기준** (아래 조건을 갖춘 환자를 층화해 뽑음)
  - 엑셀 값이 있고 품질 점검에 걸리지 않음
  - Class I과 II, normo·hypo·hyper가 섞이도록
  - TDI 경계값(−2.5 mm) 근처 환자 포함
  - NAV, PAV 값이 있는 환자 포함
  - P_50(15.4 cm 범위) 포함. P_78(10.2 cm)은 잃는 랜드마크 확인용으로만 씀
- 재측정 신뢰도: 파일럿 일부를 2주 간격으로 다시 찍어 측정자 내 ICC를 구합니다 (논문 방식).

**분할 결과 (2026-10-24 고정, `python/split_pilot.py`, seed 20261024, `Result_py/cbct_split.csv`)**

| 세트 | 인원 | 환자 |
|---|---|---|
| 파일럿 | 12 | P_5, P_7, P_9, P_24, P_30, P_32, P_41, P_44, P_50, P_54, P_60, P_69 |
| 평가 | 71 | 나머지 |
| FOV 확인용 | 1 | P_78 |
| 제외 | 3 | P_39 (본인 영상 없음), P_36·P_59 (등록번호만 맞고 생년월일 불일치) |

- 파일럿 구성: Class I 3명, Class II 9명. 수직 패턴은 hyper 7, normo 3, hypo 2명입니다.
  - 여기에 TDI 경계 근처 6명, 엑셀 NAV 있는 환자 11명, PAV 있는 환자 6명이 포함됩니다.
- Class III(3명)는 표본이 적어 층 배분에서 0명이 됐고, 모두 평가 세트에 있습니다.
- P_36과 P_59는 본인 여부가 확실해지면 평가 세트에 추가합니다.
