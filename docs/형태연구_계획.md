# 형태 연구 계획: Global vs Local 3D 형태 벡터

> 작성일: 2026-10-27
> 목적: CBCT 골격·기도의 3D 형태 벡터(Global, Local, Relation)가 Roh 기존 인자(ANB, MP-FH, TDI, PMCA, PAL)에 더해 **추가 정보**를 주는지 탐색합니다. 결과변수는 AHI입니다.
> 이 트랙은 Roh 계측 자동화 트랙(`CBCT_측정_계획.md`)과 따로 진행합니다. **기준선 M0는 엑셀 값**으로 이미 확정했습니다 (`Phase1_EDA_결과.md`).

## 2. 정한 원칙 (검토 반영)

- **우선순위:** ① 하악 Global → ② 인두 기도 프로파일 → ③ 상악 치조·구개 Local → ④ 상대관계 → ⑤ 비강
- **정렬은 두 버전을 모두 만듭니다.**
  - **frame:** 머리 좌표계(Jung FH·MSP, 원점 N) 그대로. 크기와 위치가 보존됩니다.
  - **procrustes:** 이동, 회전, 크기를 제거한 순수 형태. 중심 크기는 따로 저장해 공변량 후보로 씁니다.
- **형태(shape)와 상대 위치(relation)를 섞지 않습니다.**
- **대응점과 템플릿은 결과변수를 쓰지 않으므로** 전체 환자로 한 번 만듭니다. 반면 PCA, 스케일링, 특징 선택, 조정은 **교차검증 폴드 안에서** 합니다.
- **추가할 PC 개수는 트랙마다 2~3개로 미리 정합니다.** 결과는 유의성보다 **adj R² 증가량과 신뢰구간**으로 보고합니다.
- **분할 실패와 참조값 결측을 구분합니다.** 촬영 범위가 좁은 환자(P_50, P_78)는 ROI별로 포함 여부를 판단합니다.
- 사전학습 3D 인코더와 VAE는 선택 사항입니다. 87명으로는 학습이 어렵고, 라벨 누출 위험도 있습니다 (선행연구 검토 결과).
- **해석 한계:** CBCT는 앉아서 깬 상태, PSG는 누워서 잠든 상태입니다. 기도는 자세의 영향을 크게 받습니다.

## 3. 대응점 방법 (Phase 3 첫 구현)

- **표면:** AMASSS 마스크 → marching cubes → 머리 좌표계(mm)
- **대응점:**
  1. 중앙 크기 환자 1명의 표면 점 2,048개를 템플릿으로 씁니다.
  2. 템플릿을 각 환자에 CPD로 정합합니다 (강체 + 크기 → 비강체, α=2, β=8 mm).
  3. 정합된 각 점에서 가장 가까운 환자 표면 점을 대응점으로 씁니다.
- **QC:** 정합 잔차(평균, 95백분위)와 대응점 중복 비율을 봅니다. 중복이 많으면 대응점이 뭉친 것입니다.
- **알려진 한계**
  - **하악 마스크에 치아가 포함됩니다.** 치아 결손이나 보철이 형태 변동으로 섞입니다. DentalSegmentator로 치아를 분리하는 것이 개선 후보입니다.
  - 템플릿이 환자 1명입니다. 표본이 늘면 평균 형태로 템플릿을 다시 만들어 반복합니다.
  - ShapeWorks(입자 기반 대응점)는 별도 설치가 필요한 대안입니다. CPD 대응점의 품질이 부족할 때 도입합니다.

## 4. 결과물

`Result_py/shape/<구조>/`
- `points.npz`: 환자별 대응점
- `qc.csv`: 정합 품질
- `pc_scores_{frame,procrustes}.csv`: 환자별 PC 점수 (procrustes에는 중심 크기 포함)
- `variance_*.csv`: 설명분산
- `modes_*.png`: PC1~3의 평균 ±2SD 형태
