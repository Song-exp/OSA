**확인하지 못한 것 [미확인]**

# Part 1. PSG 원신호와 그래프 이해하기

## 1. EBM/NDF 파일의 기본 구조

> **목적:** 엑셀의 숫자 한 칸(AHI 등)과 원신호 파일 수십 개가 어떻게 이어지는지 큰 그림을 잡습니다.
> **핵심:** 원신호는 "밤새 센서가 적은 숫자의 긴 줄"입니다. AHI는 사람이 그 줄을 보고 사건을 표시한 뒤 센 결과입니다.

### 1-1. 원신호와 요약값

| 구분 | 원신호 (EBM/NDF) | 요약값 (엑셀, 리포트) |
|---|---|---|
| 모양 | 시간 순서로 늘어선 숫자. 예: Embla SpO₂ 10 Hz × 7시간 ≈ 25만 개 | 환자당 숫자 하나. 예: AHI 29.4 |
| 만든 주체 | 센서와 기록 장비 | 판독 기사가 원신호에 사건을 표시하고, 장비 프로그램이 셈 |
| 담긴 정보 | 언제, 얼마나, 어떤 모양으로 변했는지 | 하룻밤을 대표하는 결과 |
| 분석에서 | 새 지표를 만들 때 사용 (예: 산소 90% 미만 시간) | 바로 통계 분석에 사용 |

### 1-2. 파일 구성 [관찰]

한 환자 폴더에는 **채널 하나당 파일 하나**가 있습니다.

| 장비 | 원신호 파일 | 폴더당 채널 수 | 판독 파일 |
|---|---|---|---|
| Embla (55명) | `SpO2.ebm`, `C3.ebm`, `Thorax.ebm` … | 중앙값 51 (29~55) | `EN-Apnea Events.txt`(호흡·각성 사건), `EN-Stage Events.txt`(수면단계). RemLogic에서 내보낸 텍스트 |
| Nox (32명) | `spo2.ndf`, `c3.ndf`, `thorax rip.ndf` … | 중앙값 69 (60~71). 전극 저항 채널 포함 | `Data.ndb`(SQLite). 사건, 수면단계, 자세가 **판독층별로** 저장됨 |

- **채널이 여러 개인 이유 [이론]:** PSG는 뇌파, 눈 움직임, 근육, 호흡, 산소, 심전도, 자세를 동시에 잽니다. 센서마다 신호가 하나씩 나오므로 파일도 채널 수만큼 생깁니다.
- **파일 안에 들어 있는 정보 [관찰]:** 프로젝트 리더(`osa/psg_read.py`)로 확인한 내용입니다.

| 정보 | EBM | NDF |
|---|---|---|
| 채널 이름 | 헤더에 있음 | XML 헤더 `Label` |
| 단위 | 일부만 있음(`%`, `V`). 나머지는 **[미확인]** | XML `Unit` (`%`, `V`, `cmH2O`, `°`, `g`, `bpm` 등) |
| 샘플 형식 | 리더가 기록하지 않음 **[미확인]** | XML `Format`: Int16 1,896개, Int32 224개 |
| 시각 | 블록마다 시작 시각이 있음 | 구간마다 시작 시각과 정밀 샘플링 주파수가 있음 |
| 값 환산 | 정수 × 단위 이득 | 정수 × Scale + Offset |

### 1-3. 채널과 샘플링 속도

- **채널:** 센서 하나가 만든 신호 한 줄입니다.
- **샘플링 속도(fs, Hz):** 1초에 값을 몇 번 적었는지를 뜻합니다. 빠르게 변하는 뇌파는 200 Hz, 천천히 변하는 SpO₂는 Embla 10 Hz, Nox 3 Hz입니다. [관찰]
- **그래프에서 보이는 차이:** 같은 1분이라도 뇌파는 점이 12,000개, Nox SpO₂는 180개입니다. 게다가 SpO₂는 1% 단위 정수입니다. 그래서 SpO₂ 그래프는 계단 모양으로 보입니다(9-3 그림).

### 1-4. 그래프의 X축과 Y축

| 축 | 의미 | 주의 |
|---|---|---|
| X축 | 실제 기록 시각 (시:분:초) | 자정을 넘으면 날짜가 바뀝니다. 뷰어에 구간을 넣을 때는 날짜까지 적습니다. |
| Y축 | 그 순간의 센서 값 | **물리량**(SpO₂ %, Nox 자세 °, Nox 비강압력 cmH2O)은 숫자 자체에 의미가 있습니다. **상대값**(호흡 벨트 V, Embla 비강압력)은 "평소보다 커졌나 작아졌나"만 봅니다. 분류는 학습가이드 2-0절에 있습니다. |
| 맨 위 칸 | 수면단계 | 30초 단위 계단입니다. 측정값이 아니라 **판독 결과**입니다. |
| 배경 색칠 | 판독 사건(무호흡, 저호흡, 각성) | 역시 판독 결과입니다. 색이 칠해져 있다고 그 순간 파형이 반드시 그 모양인 것은 아닙니다. |

### 1-5. 측정 신호, 판독, 리포트의 관계

```
센서 ──► 원신호 파일 (.ebm/.ndf)        ← 사람이 손대지 않은 측정값
            │
            ├─► 자동 판독 (Automatic)    ← 장비 프로그램이 규칙으로 표시
            │        │
            │        ▼
            └─► 수동 판독 (Manual)       ← 기사가 파형을 보고 고치거나 추가
                     │
                     ▼
               PDF 최종 리포트 ──► 엑셀 요약값
```

- **Embla [관찰]:** 판독 파일은 최종 판독을 내보낸 텍스트 하나뿐입니다. 자동과 수동을 구분할 수 없습니다.
- **Nox [관찰]:** `Data.ndb`에 자동(Automatic)과 수동(Manual) 판독이 따로 저장되어 있습니다.
  - **사건:** 기존 코드와 엑셀 사건 수는 32명 중 22명에서 두 층을 합쳐서 셌습니다. 리포트는 "기사층 + 분석구간 + 수면 중" 규칙과 대부분 맞았습니다(`PSG_엑셀_불일치_검증.md` 3장).
  - **수면단계 (이번에 새로 확인):** 같은 30초에 두 층의 단계가 함께 들어 있습니다. 32명 중 23명은 두 층이 서로 다른 칸이 있었습니다(중앙값 134칸, 최대 P_28 353칸). 뷰어는 두 단계를 함께 그려서 수면단계 선이 위아래로 튑니다(9-10 그림). 이번 EDA와 그림은 **Manual을 우선**했습니다. 이는 `psg_reconcile.py`가 TST를 계산할 때 쓴 규칙과 같습니다.

## 2. 실제 그래프를 여는 방법과 읽는 순서

> **목적:** 프로젝트에 있는 도구로 원하는 환자의 원하는 시각을 찾아갑니다.

### 2-1. 사용할 수 있는 프로그램 [관찰]

| 프로그램 | 확인 결과 |
|---|---|
| **프로젝트 뷰어** `OSA_viewer.bat` → `python/viewer_app.py` | 사용 가능. EBM과 NDF를 모두 읽고, 수면단계와 판독 사건을 함께 표시합니다. |
| 제조사 프로그램 (Embla RemLogic, Nox Noxturnal) | 이 PC에 설치되어 있는지 확인하지 못했습니다. 사용법은 적지 않았습니다. |
| `DICOM Reader Installer.exe` | CBCT 영상용이라 PSG와 관계없습니다. |

### 2-2. 프로젝트 뷰어 사용법 (코드로 확인한 기능만)

| 하고 싶은 것 | 방법 |
|---|---|
| 열기 | `OSA_viewer.bat` 더블클릭 → 환자 번호 선택 → "PSG" → **보기**. 읽는 데 수십 초 걸림 |
| 특정 구간만 보기 | "PSG 구간" 두 칸에 시작과 끝을 날짜까지 입력. 예: `2016-07-27T23:33:30`, `2016-07-27T23:35:40`. 비우면 밤 전체 |
| 채널 목록 | 탭 "채널 1–7", "채널 8–14" …. 탭마다 7개 채널이 **파일 이름 알파벳 순**으로 들어 있음. 왼쪽 "채널 확대" 목록에 전체 채널이 번호와 함께 나옴 |
| 여러 채널을 같은 시간축에서 | 같은 탭의 7개 채널은 X축이 묶여 있음. 다른 탭 채널과 한 화면에 놓을 수는 없음 |
| 채널 하나 크게 | 그래프 더블클릭 또는 "채널 확대" 목록에서 선택 → "확대" 탭 |
| 시간 확대·축소, 이동 | 그래프 아래 도구막대(matplotlib 기본). 돋보기로 사각형을 끌어 확대, 십자로 끌어 이동, 집 모양으로 처음 화면 |
| 수면단계 | 각 탭 맨 위 칸 |
| 판독 사건 | 배경 색칠. 6종류만 칠함: 중추성·혼합성·폐쇄성 무호흡, RERA, 호흡 관련 각성, 저호흡 |
| 그림 저장 | 도구막대의 디스크 아이콘 |

**뷰어에서 주의할 점 [관찰]**
- **기록 앞 3분은 항상 빠집니다.** 구간을 직접 입력해도 마찬가지입니다(`skip_initial_seconds=180`).
- **기본 탭은 Y축이 잘립니다.** 끝값(최저 SpO₂ 등)은 확대 탭이나 이 문서 그림으로 보세요(학습가이드 6-1).
- **Nox는 사건 색칠과 수면단계가 두 겹입니다**(1-5절).
- 자발 각성, 산소저하 사건, 자세 사건은 색칠되지 않습니다.
- 사건 목록 표, "다음 사건으로" 이동, 키보드 단축키는 없습니다.

### 2-3. 그래프 읽는 순서 (매번 같은 순서로)

1. **수면단계:** 깨어 있음(W)인지 먼저 봅니다. 깨어 있는 동안의 변화는 사건으로 세지 않습니다.
2. **기록 상태:** 끊겼는지, 평평한지, 위아래 끝에 붙었는지 봅니다. 이상하면 해석보다 품질을 먼저 의심합니다(6장, 9-7~9-9).
3. **기류(Nasal Pressure, Thermistor):** 숨의 크기가 줄었는지 봅니다.
4. **흉부·복부(Thorax, Abdomen):** 숨 쉬려는 노력이 있었는지 봅니다.
5. **SpO₂:** 사건이 끝난 뒤 10~30초 **늦게** 내려가는지 봅니다.
6. **뇌파(C3)·턱 근전도(Chin):** 사건 끝에 깨어나는 반응이 있는지 봅니다.
7. **마지막에 배경 색칠(판독)과 비교합니다.** 색칠부터 보면 파형을 거기에 끼워 맞추게 됩니다.

## 4. 여러 채널을 함께 읽는 방법

> **목적:** 한 장면을 여러 채널에서 동시에 확인하는 습관을 들입니다.
> **이미 있는 판독**에서 출발해 채널 사이의 관계를 배웁니다. 파형만 보고 사건을 새로 확정하지 않습니다.

| 상황 (판독 기준) | 먼저 볼 채널 | 함께 볼 채널 | 일반적으로 기대하는 관계 [이론] | 우리 데이터 사례 |
|---|---|---|---|---|
| 정상 호흡 | Nasal Pressure | Thorax, Abdomen, SpO₂ | 기류와 흉복부가 같은 박자로 규칙적이고 SpO₂는 평평함 | 학습가이드 4-1 (P_6) |
| 무호흡 | Thermistor, Nasal Pressure | Thorax/Abdomen → SpO₂ → C3/Chin | 기류가 거의 사라짐. 폐쇄성은 노력이 계속되고 중추성은 노력도 사라짐. 끝난 뒤 SpO₂ 하락과 각성 | 학습가이드 4-2·4-3, 이 문서 9-4 |
| 저호흡 | Nasal Pressure | SpO₂, C3 | 기류가 30% 이상 줄고 뒤에 3% 이상 산소저하나 각성 | 학습가이드 4-5, 이 문서 9-3 |
| 산소포화도 감소 | SpO₂ | 바로 **앞** 시간의 기류 | 숨이 줄어든 뒤 10~30초 늦게 SpO₂가 떨어짐. 앞에 원인이 없으면 센서도 의심 | 9-3, 9-4 |
| 각성 | C3, Chin | 기류, 자세 | 뇌파가 빨라지고 턱 근육이 커짐 | 학습가이드 4-6·4-7, 9-6 |
| 자세 변화 | Position (Gravity) | 모든 채널 | 자세가 계단처럼 바뀌는 순간 다른 채널에도 움직임 잡음 | 9-5 |
| REM/NREM 전환 | 수면단계 칸 | C3, LOC/ROC, Chin | REM에서는 턱 근육이 가장 작고 눈 움직임이 커짐 | 9-6 |
| 센서 문제·잡음 | 의심 채널 | **같은 기능의 짝 채널** (Thermistor↔Nasal Pressure, Thorax↔Abdomen, SpO₂↔Pulse) | 짝은 정상인데 혼자 평탄·포화·공백이면 센서 문제를 먼저 의심 | 9-7, 9-8, 9-9 |

**판단 요령 [이론]:** 실제 몸의 변화는 **원인 → 결과의 순서**가 있습니다. 숨이 줄면 그 뒤에 산소가 떨어집니다. 반면 센서 문제는 **한 채널에서만 갑자기** 생기거나 **모든 채널에서 동시에** 생깁니다(움직임, 기록 중단).

**SpO₂ 50% 미만 규칙에 대해:** 기존 규칙이 지운 값은 **모두 정확히 0**이었습니다. 1~49% 값은 하나도 없었으므로, 이 규칙 때문에 "실제로 심한 저산소였던 값"이 지워진 일은 우리 데이터에서 일어나지 않았습니다. 다만 0이 센서가 빠진 것인지는 장비 문서로 확인하지 않았습니다. 그래서 앞으로는 이 규칙을 **"SpO₂ = 0 제외"**라고 정확히 부르는 것이 좋습니다.

## 12. 최종 결론 및 다음 작업

### ① 이번에 확인한 사실

- 87명의 원신호 파일은 모두 읽혔습니다. 주요 채널은 수면 중 대부분 정상 기록입니다.
- 기록 공백은 대부분 깨어 있을 때였습니다. P_68의 공백은 모든 채널이 깨어 있을 때 함께 멈춘 것입니다.
- SpO₂ "50% 미만" 값은 **전부 0**이었습니다. 1~49%인 값은 없습니다.
- 품질 문제를 그림으로 확인한 채널은 P_28 흉부, P_50 턱 근전도, P_59 서미스터입니다.
- Nox는 사건뿐 아니라 **수면단계도 두 판독층이 겹쳐** 읽힙니다(23/32명). 뷰어 화면에도 그대로 나타납니다.
- 장비 간에 채널 이름, fs, 단위 기록, 자세·코골이 채널 보유가 다릅니다(5-2).
