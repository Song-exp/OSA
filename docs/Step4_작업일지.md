## 0. 결론

1. **확정 인자(최종 ANB + Pog-Ba)와 크기 축 위에 남는 연동·기구학·탐색 신호는 없다.** FDR q < 0.05는 0건이다. 나중에 편입한 연조직 피처(혀·저작근·부비동, 2-3)도 같다.
2. 확정 인자 위에서 p < 0.05로 반복된 신호(주 분석 12건)는 **모두 부위 크기 피처**다. 크기 축(SIZE_PC1)을 넣으면 전부 사라진다(0건).
   - 따라서 Step 3에서 크기 축 하나로 묶어 검정한 판단이 맞았다.
3. 크기 축 안에서는 **두개저 크기(측두·사대)**가 가장 일관된다. 85명 표본에서 크기 축 위에서도 약하게 남는다(p 0.02~0.03).
4. fold 안 요인분석(EFA)은 **설계 결함을 고친 수정판**(요인을 분산순으로 정렬해 전부 검정 + 세트 전체 묶음 검정)으로 다시 봤다. 요인별·묶음 모두 이득이 없다. 지렛대 피처도 이득이 없다.
5. 이전 후보였던 아래 앞니 각도(L1_MP_deg)는 확정 인자 위에서 약하고(p=0.07), 크기 위에서 사라진다. **후보에서 내린다.**

## 1. 설계 (결과 보기 전 기록)

- **기준 모델:**
  - 확정 = B0 + 최종 ANB(등급 A~D) + Pog_Ba_ant
  - 확정 + 크기 = 위 + SIZE_PC1
- **대상:**

| 부분 | 내용 | 수 |
|---|---|---|
| 4-A (수정판) | fold 안 EFA. 세트 = 골격+설골(`skel`) / +Eb(`skel_eb`) / +기도 프로파일(`skel_eb_air`, 기도 매개 정보라 참고용). 전체 적합 요인을 적재량 제곱합 순으로 정렬해 **요인 전부(6·7·9개)를 하나씩** 검정하고, **세트 전체 묶음**도 검정. 학습 fold마다 재적합하고 코사인으로 정렬 | 22 + 묶음 3 |
| 4-B | 지렛대 `lever_Pog_mm`, `lever_Hy_mm`, `lever_arm_Pog_sup` | 3 |
| 4-C | 탐색 역할 피처 전부(확정 인자·SIZE_PC1 제외, 50명 이상 값 있음) | 63 |

- **판정:** 표본·가설·기준·부분별 BH-FDR q < 0.05. 주 판단은 최종표 판, 주 분석 59명이다.
- 엑셀 0값 처리와 Eb 확정은 Step 4 피처에 영향이 없다.
- 코드: `python/osa_experiments.py S4 --source final_v2` (`CONFIRMED`, `REFS`)

## 2. 결과

### 2-1. 4-A EFA (fold 안, 수정판)·4-B 지렛대

**처음 설계의 결함과 수정:**
- 처음 판(`S4AB_efa_lever_v3.csv`)은 sklearn 출력 순서의 요인 1~3만 검정했다. 그런데 varimax 출력은 분산순이 아니라서, 실제 순위는 skel 1·3·2위, skel_eb **1·7·5위**였다(2~4위 미검정).
- 묶음 검정도 없었다.
- 수정판은 요인을 정렬해 전부 검정하고, 묶음 검정을 더했다. fold 정렬은 원래부터 문제없었다(|cos| 중앙값 0.99).

| 항목 | 가장 큰 결과 | 판정 |
|---|---|---|
| EFA 요인별 (22개 × 두 기준 × 두 표본 × H1·H2) | p < 0.05 0건. 최소 p = 0.055 (skel_eb_air 3위, 85명 H2, ΔR² +0.003) | 이득 없음 |
| EFA 세트 전체 묶음 | 주 분석 확정 위 ΔR² skel −0.18 / skel_eb −0.22 / skel_eb_air −0.40 (H1), F p 0.40~0.99 | 이득 없음, 묶으면 과적합 |
| 지렛대 | 확정 + 크기 위 `lever_Pog_mm` H2 +0.021 (p=0.077, 50회 중 86% 개선) | 이득 없음 |

- 1차 실행에서 EFA 요인1은 하악 후퇴 축이었다(Pog_Ba와 −0.91). 확정 인자에 Pog_Ba가 들어가 있어 겹친다.

### 2-3. 4-D 연조직 피처 (S6, 사전 등록)

혀 형태, 저작근(측두근 제외), 부비동을 피처 표에 편입하고(그룹 "4그룹 연조직", [정의서](파생변수_정의서.md) 7-1절) 같은 기준으로 검정했다. 설계는 결과 보기 전에 실험기록 "S6 사전 등록"에 적었다.

| 구분 | 피처 | 확정 인자 위 (주 분석 H1 / H2) | B0 위 | 판정 |
|---|---|---|---|---|
| 사전 가설 | tongue_back_ant (혀뿌리 위치) | −0.029 / −0.031 | +0.034 (p=0.041), 85명 +0.055 (p=0.007) | 실패 (확정 인자에 흡수) |
| 사전 가설 | tongue_mandible_ratio | −0.029 / −0.027 | 음수 | 실패 |
| 탐색 | tongue_c_ant (혀 무게중심 앞뒤) | −0.000 / +0.012 | **+0.111 / +0.142 (q=0.037 / 0.015)** | 흡수. 확정 + 크기 위 H2 +0.042 (p=0.021, q=0.28)만 잔여 |
| 탐색 | lat_pterygoid_mL | +0.020 (p=0.042) / −0.010 | **+0.092 (q=0.041)** | 흡수 |
| 탐색 | 그 외 11개 | p ≥ 0.05 | 일부 p < 0.05 | 이득 없음 |

- 탐색 FDR q < 0.05 5건은 전부 B0 위이고, 확정 인자 위에서는 0건이다.
- 이유(Spearman, 85명):
  - 혀 위치는 Pog_Ba와 0.46~0.61로, **하악 후퇴 축**이다.
  - 혀·저작근 부피는 SIZE_PC1과 0.72~0.79, 남성과 0.61~0.72로, **크기 축**이다.
- 해석: 연조직은 새 정보를 주지 않는다. 다만 "혀가 뒤에 있고 구조가 작을수록 AHI가 높다"는 방향이 골격 결론과 같아서, **보조 근거**로 쓸 수 있다.
