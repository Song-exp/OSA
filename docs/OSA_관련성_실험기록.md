# OSA 관련성 실험 기록

갱신: 2026-11-18. 파생변수([파생변수 정의서](파생변수_정의서.md))로 "골격이 기도와 OSA 중증도를 설명하는가"를 단계별로 보는 실험의 설계와 결과다. 계측 규칙 자체의 개선은 [CBCT 계측기준 개선 기록](CBCT_계측기준_개선기록.md)에 따로 있다.

현재 분석은 문서 후반의 **83명 Step 1~4**와 **측정 규칙 점검·민감도 분석**을 따른다. 앞부분의 59명 교차검증 설계·잠정 결론·다음 작업은 당시 기록이며, 현재의 분할 없는 계수 분석과 구분한다.

코드: `python/osa_experiments.py` (단계별 실행: `python osa_experiments.py E3`) · 출력: `Result_py/analysis/osa_experiments_v1/E*.csv`

## 고정 원칙

- **표본:** 주 분석은 PSG 확인이 끝난 59명이다. 민감도 분석은 측정한 85명 중 PSG 값이 있는 환자로, PSG 확인 중인 환자를 포함한다. 골격 → 기도 단계(E2)는 PSG가 필요 없어 85명 전체를 쓴다. 85명 모두 규칙 개발에 쓰인 자료라 독립 검증군이 아니다.
- **기준 모델 B0:** 나이 + 성별(검증값) + BMI. 기도 변수(PMCA·PAL)는 매개변수라 OSA 모델(2-B)에 넣지 않는다.
- **성능:** 반복 5겹 교차검증 50회의 교차검증 R², 즉 학습에 쓰지 않은 환자 예측력이다.
  - ΔR² 범위는 반복 50회의 2.5~97.5 백분위로, 신뢰구간이 아니다.
  - 비교는 모델마다 필요한 값이 모두 있는 환자로, 같은 환자 안에서 1:1로 한다.
- **누출 방지:** PLS·EFA 점수는 fold 학습 환자로만 적합한다(E2·E3·E5의 PLS). E4의 EFA 요인은 전체 표본 적합값이라 선별용으로만 쓴다.
- **사전 가설:** Pog_Ba_ant, Overjet_mm, PLS 골격 점수, tongue_MMV. 나머지 피처는 탐색용이며 BH-FDR q를 같이 보고한다.
- **기록 방식:** 한 단계씩 실행하고 결과·판단·다음 작업을 이 문서에 쌓는다. 이전 결과는 덮어쓰지 않는다.

## 목적 단계와 실험 대응

실험은 아래 목적 단계(Step 1~4)를 따른다. 1차 실행(v1)의 실험 번호 E1~E7b는 결과 보존을 위해 그대로 두고, 어느 Step에 해당하는지 표시한다. 보완 실행(v2)은 Step 번호(S1~S4)로 바로 기록한다.

| 목적 단계 | 무엇을 보는가 | 1차(v1) 실험 | 보완(v2) |
|---|---|---|---|
| **Step 1** 기존 지표 기준선 | 기존 Roh 지표의 AHI 설명력, 기도 변수를 같이 넣었을 때 골격 효과가 가려지는지 | E1, E7, E7b | S1: H1·H2, 조정 R²·교차검증 RMSE, "ANB 위에 +PMCA·PAL" 가림 효과, 지표별 엑셀↔자동 |
| **Step 2** 골격 → 기도 (2-A) | 새 골격·연동 피처가 기도 단면적·길이·납작화(PMCA·PAL·HD)와 관련되는지 | E2 | S2: ANB 포함, FDR |
| **Step 3** 순수 골격 총효과 (2-B, 주 가설) | 기도 변수 없이 사전 가설 피처가 **기존 지표(ANB) 대비** 설명력을 높이는지. H1 = log AHI, H2 = log 앙와위 AHI | E3, E5, E6 | S3: H1·H2 모두, B0 위·ANB 위, tongue_MMV 포함, 교호작용, 보조 목표 FDR |
| **Step 4** 연동·기구학 탐색 | 4-A VARIMAX EFA, 4-B 지렛대 민감도, 4-C FDR 탐색 | E4 | S4: **fold 안 EFA**(골격+설골 / +Eb / +기도 프로파일), 지렛대·탐색 피처를 B0 위·ANB 위에서, H1·H2 |

**목적 문서와 결과가 다른 점 (1차 실행 기준):**
- Step 1의 전제("기존 지표로는 예측이 안 된다")는 데이터와 맞지 않는다. 자동 ANB 하나로 R²가 0.07 → 0.21이 된다.
- 데이터에 맞는 서술은 **"기존 지표 중 ANB만 일하고, 기도 변수와 결측이 많은 지표를 섞으면 그 효과가 가려진다"**이다.
- 그래서 Step 3의 판단 기준은 "B0 대비 상승"이 아니라 **"ANB 대비 상승"**이다.

### S2c 매개분석 설계 (2026-11-16, 결과 보기 전 작성)

- **질문:** 크기 축이 AHI와 관련되는 것(Step 3 S5)이 기도 단면적을 거치는가. 그리고 단면적이 머리 크기에 비해 좁은 것이 AHI와 관련되는가(상대성장 구분).
- **표본:** 주 분석 59명(PSG 필요), 민감도 85명. 최종표 판(ANB A~D).
- **변수:**
  - X = SIZE_PC1
  - 매개 M = 평균 단면적 PAV/H_col(주), PAV, PMCA(보조)
  - Y = log AHI(H1), log 앙와위 AHI(H2)
  - 공변량 = B0(나이·성별·BMI). 민감도로 B0 + 최종 ANB.
  - X·M은 표준화한다.
- **추정:**
  - a 경로: M ~ X + 공변량
  - b 경로: Y ~ M + X + 공변량
  - 간접효과 = a×b, 직접효과 = c′, 총효과 = c
  - 간접효과는 비모수 부트스트랩 2000회 백분위 95% 구간으로 본다. 0을 포함하지 않으면 매개가 있다고 본다.
- **상대성장 확인:** B0 + ANB + SIZE_PC1 위에 평균 단면적을 넣었을 때 교차검증 ΔR²와 F 검정. 즉 "크기 대비 좁은 단면적"이 AHI를 더 설명하는가.

## B 단계 사전 등록: 골격 배치·크기·비율 분해 (2026-11-16, 결과 보기 전 작성)

**문제 제기 (사용자 검토 반영)**
- EFA는 사람 간 정적 배치의 공분산을 요약한 것이다. F1은 "하악 전체가 두개저 대비 얼마나 뒤에 있나"(Pog_Ba와 −0.91)였다.
- 진짜 질문은 다음 네 가지가 사람마다 어떻게 다르고, 그 조합이 AHI와 어떻게 관련되는가다.
  1. 두개저 대비 하악 위치
  2. 상악 대비 하악 위치
  3. 뼈 그릇의 절대 크기
  4. 부위 간 길이·각도 **비율**
- 지금까지 비율 피처가 거의 없었다. Step 4의 "연동" 명칭도 실제로는 정적 배치였다.

**B1. Pog_Ba 분해** (정중 좌표계, PNS 원점이라 항등식이 성립)

- 모델: B0 + ANB + Pog_PNS_ant + PNS_Ba_depth (두 성분 따로)를 확정 모델(B0 + ANB + Pog_Ba)과 비교하고, 성분별 계수를 본다. B0 위 성분 각각도 본다.

**B2. ANB 분해**
- SNA, SNB: N에서 S 방향과 A·B 방향 사이 각, 정중 시상면 투영
- B0 + SNA + SNB를 B0 + ANB와 비교해, 상악 전방(SNA)과 하악 후방(SNB) 중 어느 쪽이 일하는지 본다.

## E 단계 설계 변경: AMASSS 벡터 공동 PC축 (2026-11-16, 사용자 지시, 결과 보기 전 작성)

- **위 "E 단계 사전 등록"(구조별 블록 PCA)은 실행 중에 중단하고 대체한다.** 구조마다 따로 PCA하면 구조 사이의 **배치**(하악이 상악·두개저에 대해 어디에 어떻게 놓였나)가 축에 담기지 않는다. 사용자 목적은 "AMASSS로 뽑은 얼굴 벡터들끼리 PC축을 구성해 벡터 간 배치에 따른 차이를 파악"하는 것이다.
- **자료:** MAND·MAX·CB SSM 대응점(구조당 2048점)을 정중 좌표계(PNS 원점, Po 미사용)로 옮겨 **한 벡터로 이어 붙인다**(6144점 × 3). 세 구조 모두 정합 정상인 환자만 쓴다.
- **두 판:**
  - **F1 형태(form):** 이어 붙인 좌표 그대로 PCA. 크기 + 구조 간 배치 + 모양.
  - **F2 배치·모양:** 이어 붙인 전체 구성에 한 번의 GPA를 적용한다(전체 위치·회전·크기만 제거, **구조 사이 상대 배치는 보존**). 그다음 PCA하고, 전체 중심 크기(log)는 따로 둔다.
  - 민감도: CB 품질 문제가 있어 MAND + MAX만 이은 판(F2-MM)도 만든다.
- **축 해석:** PC마다 +1 SD당 구조별·부위별 평균 변위, 하악 중심 대 상악 중심의 상대 이동(앞뒤·위아래), 그리고 ANB·Pog_Ba·SIZE_PC1·성별·LAFH_ratio와의 상관을 기록한다. 상위 축은 ±2 SD 그림을 그린다.
- **검정:** 판마다 PC1~10 하나씩, 그리고 PC1~5 묶음. 기준은 확정 인자 위와 확정 인자 + SIZE_PC1(동결) 위다. 주 분석·85명, H1·H2, FDR. 판정은 두 단계 기준이다.

### D5·D7·D8 결과 (2026-11-16)

**D5 상악 후방–비인두**

**D7 상대성장**
- log 중심 크기는 성별 보정 후 전체 구성 모양 분산의 **7.0%**를 설명한다(순열 p=0.002). 상대성장 모양 변화는 실재한다.

- AHI: **log CS(순수 크기)**는 기존 인자 + VERT_Z 위 주 H1 +0.038 (p=0.011, 84%), 85명 +0.040 (p=0.008, 98%)이다. 상대성장 모양 점수는 AHI와 무관하다(앙와위 초과만 주 p=0.064).

**D8 기도 프로파일–주변 뼈**
- **사전 가설 기각:** 기도가 가장 좁은 위치(`AW_min_pos`)는 ANB·Pog_Ba·VERT_Z·설골 높이와 무관하다. **연구개 길이만** 관련된다(길수록 최소 위치가 위·구개 뒤, β +0.049, p=0.039). 하악 후퇴가 혀 뒤 좁아짐을 만든다는 가정은 이 정적 CBCT에서 확인되지 않는다.
- 기도 단면 모양 PCA: PC1(68%)은 전체 크기, PC2(19%)는 위(구개 뒤) 대 아래(혀 뒤) 상대 폭, PC3(6%)은 중간부 좁아짐이다.

**판단:**
1. 비인두 크기는 골성 비인두 깊이로 정해지지만, 앙와위 의존성과 관련되는 것은 비인두 공간 자체(연조직 포함)다. → 비인두 평균 단면적을 **앙와위 의존성 후보**로 둔다.
2. 크기 축은 순수 크기 효과다(상대성장 모양 아님). VERT_Z와 함께 넣을 때 더 강해져, 둘은 서로 보완적이다.
3. 기도 최소 위치는 골격이 아니라 연구개 길이로 정해진다.

## P 단계 사전 등록: 원신호 판독으로 실제 앙와위 의존성 계산 (2026-11-16, 결과 보기 전 작성)

- **목적:** 지금까지 쓴 "앙와위 초과"(log 앙와위 AHI − log 전체 AHI)는 비앙와위 AHI와 앙와위 시간이 없어 쓴 대리 지표다. 판독 파일의 자세 정보로 **앙와위·비앙와위 AHI와 앙와위 수면시간**을 직접 계산해, 가장 견고한 결론인 "ANB → 누운 자세에서 악화"를 정확한 지표로 다시 확인한다.
- **자세 정보 확인:**
  - Embla: 55명 중 52명은 사건 파일과 수면단계 파일 모두에 자세 열이 있다(3명은 없음).
  - Nox: 32명 모두 판독 데이터베이스에 자세 구간 마커가 있다.
  - 자세 채널 원신호는 값의 의미가 확인되지 않아 쓰지 않는다(원신호 EDA 권고).
- **계산 규칙 (리포트 사건 수와 일치가 검증된 기존 규칙 그대로):**
  - **Embla:** EN-Stage Events의 수면 epoch(각성 제외)과 그 자세, EN-Apnea Events의 호흡 사건(OA·CA·MA·저호흡)과 사건 행의 자세
  - **Nox:** Manual 마커가 가장 많은 판독층, 같은 30초는 Manual 단계 우선, 분석 구간(period) 안의 수면 epoch, 수면 epoch 안의 Manual 호흡 사건. 자세는 같은 층의 position 구간으로 epoch 중앙·사건 시작 시점에 붙인다.
  - 앙와위 AHI = 앙와위 사건 수 ÷ 앙와위 수면시간(h). 비앙와위 AHI = 나머지 자세(좌·우·엎드림) 사건 ÷ 해당 수면시간. 앉음·자세 미상은 비앙와위 계산에서 뺀다.
  - **자세 의존 지표 `POS_ratio`** = log((앙와위 AHI + 1) ÷ (비앙와위 AHI + 1))
  - **POSA**(Cartwright): 앙와위 AHI ≥ 2 × 비앙와위 AHI. 앙와위·비앙와위 수면이 각각 30분 이상일 때만 판정한다.
- **검증:** 계산한 전체 AHI·앙와위 AHI를 같은 검사 리포트의 AHI·Supine AHI와 비교한다. 엑셀 요약 검사와 원신호 검사가 같은 환자(`SameExam`)만 분석에 쓴다.
- **사전 가설:**
  - **P1:** ANB가 클수록 `POS_ratio`가 크다(B0 위, 계수 +). 주 분석 p < 0.05.
  - **P2(기전):** ANB는 앙와위 AHI와 관련되고 비앙와위 AHI와는 약하다. 두 결과에 따로 회귀해 계수를 비교한다.
- **보조:** 앙와위 수면 비율 보정, POSA 여부 로지스틱, 수직 배치 지표·Pog_Ba도 같은 방식으로 본다.
- **표본:** 주 분석(발굴 59명 중 SameExam·자세 있음), 확장(최종 80명 중 해당 환자)

| Step 2: 기도 대표값 대체 모델 | 77 | 0.374 (0.300) | 0.423 (0.355) |

※ 이 표는 모델별 완전자료 결과다. 인원이 다르므로 행 사이 R² 차이를 증분으로 해석하지 않는다. 같은 환자에서의 대체·추가 결과는 보고서 개별 표를 따른다.

## A~F 측정 인자별 OSA 연관성 선별

- 83명 코호트에서 `log(AHI+1)`과 `log(앙와위 AHI+1)` 각각에 `나이 + 성별 + BMI + 인자 하나` 선형회귀를 적합했다. 인자별 완전자료 환자는 24~83명이다. 엑셀·자동 계측값은 각각 분석했다.
- 피처 정의 보고서와 같은 A~F 목록에서 직접 계측값과 해부학적 비율·기하 계산값을 사용했다. G의 통계적 2차 파생값과 A~F에 분류된 `SoftLoad_MMV`, `tongue_MMVhull`, `tongue_MMV`는 제외했다. 원천별 인자 수는 A 11, B 37, C 14, D 56, E 7, F 28이다.
- 153개 인자를 결과별로 전부 적합했다. 각 결과의 153개 p값에 별도로 Benjamini–Hochberg FDR을 적용했다. 아래 건수는 엑셀·자동 버전과 같은 해부학적 개념의 여러 지표를 포함한 결과 행 수다.

| 결과 | p < .05 | FDR q < .05 |
|---|---:|---:|
| 전체 AHI | 33 | 6 |
| 앙와위 AHI | 38 | 9 |

- 두 결과에서 공통으로 FDR q < .05인 인자는 엑셀 ANB, 자동 ANB, 엑셀 Nperp-Pog, Pog–Ba 앞뒤 거리, PNS 기준 Pog·B점 앞뒤 위치다. 앙와위 AHI에서 혀 무게중심의 앞뒤 위치(β −.362, q=.0119), 과두 축상각(β +.363, q=.0300), 얼굴축 대리 지표(β +.323, q=.0473)가 추가됐다.
- 이 결과는 조합 회귀의 후보 선별에 쓴다. 개별 인자의 ΔR²는 해당 인자 모델과 나이·성별·BMI 기준 모델을 같은 환자에서 적합해 계산했다. 서로 다른 표본의 ΔR²를 바탕으로 최종 조합을 확정하지 않는다.
