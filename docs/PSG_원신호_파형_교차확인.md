# PSG 원신호(파형) 교차확인

- **목적:** `PSG_엑셀_불일치_검증.md`의 결론을 원본 파형 파일로 다시 확인합니다. 그 문서는 엑셀, 리포트 PDF, 판독 파일(Embla `EN-Apnea Events.txt`, Nox `Data.ndb`)을 대조해 얻은 것입니다.
- **사용한 파일:** 환자 폴더의 SpO2 파형 파일입니다. Embla는 `SpO2.ebm`(P_20은 `SpO2_PDS.ebm`), Nox는 `spo2.ndf`를 썼습니다. 수면 구간과 판독 사건은 기존과 같은 판독 파일에서 가져왔습니다.
- **코드와 결과:** `python/psg_waveform_check.py`, `Result_py/psg_waveform_check.csv`
- **대상:** 87명 전원. 87명 모두 파형을 읽었습니다.
- **변경하지 않은 것:** 원본 PSG 파일, 엑셀, 기존 코드는 수정하지 않았습니다.

## 한 줄 결론

**파형으로 확인해도 기존 결론은 그대로입니다.** 같은 검사로 확인된 73명은 파형에서 직접 잰 최저 SpO₂가 리포트와 73명 모두 일치했습니다. 엑셀 값이 다른 검사에서 왔다고 판정한 14명은 파형과도 맞지 않았습니다. 그중 P_65와 P_69는 엑셀이 이전 검사 값을 적었다는 판정이 파형으로 한 번 더 확인됐습니다. 원인 미확인이던 P_67도 엑셀 요약값이 이 원본 검사에서 온 것이 아니라는 점까지는 확인됐습니다.

## 1. 무엇을 확인했고, 무엇은 하지 않았나

| 확인 항목 | 파형에서 잰 방법 | 비교 대상 |
|---|---|---|
| 검사 날짜 | SpO2 파형 기록 시작 시각 | 판독 파일 날짜, 리포트 검사일 |
| 기록 길이 | SpO2 파형 시작부터 끝까지 | 리포트 TST(총수면시간) |
| 최저 SpO₂ | 원 샘플 최솟값. 전체 기록과 수면 중을 각각 계산하고 50~100% 밖 값은 잡음으로 제외 | 리포트·엑셀 Lowest SpO₂ |
| ODI(산소저하지수) | 직전 120초 최고값보다 3%p 이상 낮은 상태가 10초 이상 이어지면 1회로 셈. 수면 중 시작한 것만 세고 TST로 나눔 | 리포트·엑셀 ODI |
| 판독 사건이 파형 위에 있는가 | 판독된 무호흡·저호흡 시작 시각이 파형 기록 안에 있는지 | — |
| 사건 뒤 산소 하락 | 사건 직전 30초 최고값보다 사건~사건 끝+30초 최저값이 3%p 이상 낮은 비율 | 참고용 |

**하지 않은 것:** 무호흡과 저호흡을 파형에서 새로 판독하지 않았습니다. AHI는 기사가 호흡, 흉복부 움직임, 뇌파를 함께 보고 판정한 결과라서, 단순 규칙으로 다시 세면 판독과 같은 기준이 되지 않습니다. 그래서 숫자로 바로 재현되는 최저 SpO₂와 ODI만 다시 쟀습니다.

**ODI는 참고값입니다.** 장비 알고리즘(Embla RemLogic, Nox Noxturnal)은 공개되어 있지 않고 위 규칙과 다릅니다. 따라서 대략 맞는지만 보는 용도이고, 리포트 값을 대체하지 않습니다.

## 2. 결과 요약

| 항목 | 결과 |
|---|---|
| 파형 읽기 | 87/87 성공. 수면 중 SpO₂ 유효 비율 중앙값 99.4%, 최저 87.4%(P_68) |
| 파형 날짜 ↔ 판독 파일 날짜 | 86/87 같은 검사. 나머지 1명(P_39)은 판독 TXT 날짜만 하루 늦음 |
| 파형 날짜 ↔ 엑셀 요약 리포트 날짜 | 73명 같음 / 11명 다른 검사 / 3명은 엑셀과 맞는 리포트 없음 |
| 기록 길이 ≥ 리포트 TST | 84/84 (리포트 TST가 있는 전원) |
| 최저 SpO₂, 같은 검사 73명 | **73/73 일치(±1)**. 이 중 67명은 정확히 같음 |
| ODI, 같은 검사 73명 | 상관계수 0.993, 차이 중앙값 1.4. 68명은 ±5 이내 |
| 판독 사건이 파형 기록 안에 있음 | 87명 모두 100% |
| 판독 무호흡 뒤 3% 이상 산소 하락 | 중앙값 93% |
| 판독 저호흡 뒤 3% 이상 산소 하락 | 중앙값 49% |

저호흡 비율이 낮은 것은 이상이 아닙니다. 저호흡은 산소 하락 대신 **각성**으로도 판정할 수 있기 때문입니다(AASM 3% 또는 각성 기준). 반면 무호흡은 산소가 떨어지지 않아도 성립하는데도 대부분 산소 하락을 동반했습니다.

## 3. 검사 날짜

- 파형 시작 시각이 자정 이후인 사람(P_12, P_31, P_35, P_44, P_61, P_79)은 날짜 표기가 '밤 날짜'와 '달력 날짜'로 하루씩 다르게 보입니다. 시작 시각이 0시~2시라서 **같은 검사**입니다.
- **P_39:** 파형 시작은 2011-12-09 22:30이고 리포트도 12-09인데, 판독 TXT의 Recording Date만 12-10입니다. 판독 파일 표기 차이로 보이며, 같은 검사입니다. P_39는 CBCT 동일인 문제로 이미 제외 대상입니다.
- **다른 검사 11명**(P_8, P_9, P_10, P_19, P_26, P_41, P_42, P_43, P_45, P_47, P_77)은 기존 문서의 "서로 다른 검사 날짜" 11명과 정확히 같습니다. 폴더에 있는 원본 파형은 엑셀 요약값을 만든 검사가 아니라는 뜻입니다.

## 4. 최저 SpO₂

- **같은 검사 73명은 모두 맞았습니다.**
  - 70명은 기록 전체 최솟값과 일치했습니다(깨어 있는 시간 포함).
  - 3명(P_14, P_22, P_60)은 수면 중 최솟값과 일치했습니다. 이 3명은 깨어 있을 때 더 낮은 값(80, 84, 88)이 있었고, 리포트는 그 값을 뺀 것으로 보입니다.
  - 따라서 리포트 Lowest SpO₂가 전체 기록 기준인지 수면 중 기준인지는 사람마다 다를 수 있습니다. 분석 변수로는 리포트 값을 그대로 쓰면 됩니다.
- **다른 검사 14명은 파형 값과 엑셀 값이 다릅니다.**

## 5. ODI (참고값)

- **같은 검사 73명:** 파형 ODI와 리포트 ODI가 거의 같은 선 위에 있습니다(r = 0.993). 리포트 ODI가 실제 신호에서 계산된 값이라는 점이 확인됩니다.
- ±5를 넘은 5명(P_11, P_50, P_51, P_59, P_68)은 모두 ODI가 높은 중증 환자입니다. 산소 하락이 연달아 일어나면 단순 규칙이 두 번을 한 번으로 세기 때문에 파형 값이 더 작게 나옵니다. P_68은 SpO₂ 유효 비율이 87%로 가장 낮습니다.
- **P_22:** 파형 10.1, 리포트 6.1, 엑셀 29.8입니다. "엑셀 ODI 칸에 앙와위 AHI가 들어갔다"는 기존 판정과 맞습니다.

## 7. 한계

- SpO₂ 채널만 사용했습니다. 호흡 기류와 흉복부 신호로 무호흡 개수를 다시 세지 않았으므로, **AHI 자체를 파형으로 검증한 것은 아닙니다.** 다만 같은 검사에서 최저 SpO₂와 ODI가 리포트와 맞으므로, 리포트가 이 파형에서 나왔다는 점은 확인됩니다.
- 사건 수가 맞지 않는 환자(P_50, P_75, P_76, P_35)에서 판독이 맞는지 틀린지는 판단하지 않았습니다. 확인하려면 뷰어로 해당 구간을 사람이 직접 보아야 합니다.
- 다른 검사 14명은 폴더에 엑셀 요약값을 만든 검사의 파형이 없습니다. 따라서 그 엑셀 값 자체는 파형으로 확인할 수 없습니다.
