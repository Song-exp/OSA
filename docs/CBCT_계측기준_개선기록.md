# CBCT 자동 계측기준 개선 기록

갱신: 2026-11-16. 후속 작업의 시작점은 이 문서다. 과거 54명 보고서와 초기 파일럿의 채택 결론은 당시 상태이며, 아래 85명 개발 실험과 구분한다.

## 목표와 고정 원칙

- 대상 85명(P_39·P_78 미포함). 과거 제외되었던 31명도 개발에 포함했다. 이 85명은 모두 개발 자료이며 독립 검증군으로 부르지 않는다.
- 전문가가 직접 점을 찍는 단계 없이 자동 규칙으로 계측값을 복원한다. 같은 규칙을 전원에 적용하고 단일값·후보 범위·자동 보류로 반환한다. 환자 ID별 보정 규칙은 두지 않는다.
- 실제 좌우 비대칭을 허용한다. 반대편 반사·대칭 강제로 좌표를 교체하지 않는다. 과거 대칭 보정이 포함된 기존값은 비교 기준으로만 보존한다.
- 후보를 찾을 때 현재 대상점 좌표나 엑셀 오차로 ROI·후보를 고르지 않는다. 기존점은 후보 생성 이후 교체 필요 판단에만 사용한다. 엑셀은 모든 후보·분기를 정한 뒤 후향 비교한다.
- AMASSS/SSM 표면 대응은 국소 탐색 영역 안내다. 전달된 점이나 PCA 재구성점을 최종 해부학점으로 간주하지 않는다. 원래 3D 대응점을 저장 좌표계에서 정확히 역변환한다.
- 후보의 반복 안정성은 해부학적 정확도와 다르다. 원본 CT와 마스크도 같은 ROI·정의를 공유하므로 독립 정답 검증이 아니다. 범위는 조건별 민감도이며 신뢰구간이 아니다.
- 보류로 인한 평균오차 감소를 개선으로 주장하지 않는다. 전체 85명 중 숫자 제공 인원과 같은 숫자 제공 환자의 오차를 함께 비교한다.
- 기존 ALI 좌표·운영 result.json·기존 보고서는 보존하고 실험별 새 폴더에 기록한다.
- 진행 방식: 한 번에 한 단계를 실행하고 전수 결과·실패 사유·채택 여부·다음 작업을 이 문서에 기록한다. 다음 단계에서 이전 결과를 덮어쓰지 않는다(2026-11-15 사용자 지시).

## A/Pog v1 상세 결론

- 참조 환자 P_5·11·28의 검수되지 않은 ALI 좌표는 표면 대응 ROI 안내에만 사용했다. 해당 환자 자신은 참조에서 제외했다. 후보 탐색은 현재 A/Pog·Me·대칭을 쓰지 않는다.
- A 후보 영역 P_15·44, Pog 후보 영역 P_28·69. 영역의 계측값 범위가 좁아 숫자가 나오는 경우와 점 좌표의 안정성을 구분했다.
- v1은 앞쪽 윤곽의 극점과 2 mm 양쪽 지지 조건에서 실패가 많았다. 후보가 없는 결과는 검출 규칙의 실패이며 해부학점이 없다는 뜻이 아니다.
- A/Pog 단독 변경에서 일부 ANB·Nperp-Pog가 개선됐으나 두 A 후보의 Nperp-A 오차는 증가했다. Pog 숫자 제공은 85→46명이다.
- 이전 FH 결합 대비: ANB 제공 83→72명, Nperp-A 83→73명, Nperp-Pog 83→46명, MP-FH 83명 유지. 같은 환자끼리 Nperp-A MAE 1.699→1.715 mm, Nperp-Pog 4.216→4.182 mm. 제공률 감소를 상쇄하는 개선이 아니다.
- 24개 단위 테스트 통과(Po 10·Or 6·A/Pog 8). 입력·기존 FH 결과 불변, 자기 참조 제외, 무관 계측값 불변, MP-FH 이전 결과 재현을 검증했다.

## 1-1. A/Pog 후보 구조 게이트 결과 (v3)

이번 한 단계는 후보의 구조 조건 추가에 한정했다. 신규 후보 생성·개인별 최적 조건 선택·Po/Or 재수정·나머지 기준점 작업은 하지 않았다.

- v2의 85명·170점·24조건(4080개 실행 기록)과 교체 필요 분기를 고정했다. 조건별 적격 후보 4199건에만 구조 게이트를 추가했다. 반복 조건에 같은 점이 포함되므로 4199를 고유 점 수로 해석하지 않는다.
- 치아 모델의 라벨을 확인했다. 1~32는 영구치, 33~52는 유치, 53은 하악·54는 상악·55는 하악관이므로 1~52만 치아로 처리한다. 85명 모두 해당 분할 파일이 있었다.

- 치아 분할 생성 당시의 큰 절단창에는 기존 Pog·Me가 쓰였다. 이번 독립 후보 생성 ROI는 바꾸지 않고 치아 분할은 사후 거부에만 사용했다. 후보의 저장 범위를 확인했지만 치아 라벨을 독립 정답으로 간주하지 않는다. 치아 0 라벨이 치아 부재의 정답이라는 뜻도 아니다.

## 1-2. 남은 오차 원인 분리 결과 (2026-11-16)

이번 단계는 진단만 했다. 신규 후보, 축 선택, 보정 규칙은 만들지 않았다. v3 통과 후보·분기를 읽기만 했다. 기존 ALI Po/Or로 만든 같은 FH에서 점만 바꾼 계측, 그리고 FH 앞뒤 기울기 δ(−6~+6°, 0.5° 간격)만 바꾼 계측을 분리했다. δ를 바꿀 때 기존 Pog 규칙(Me+3~20 mm 창의 하악 최전방점)은 돌린 축에서 다시 실행했다. 엑셀은 계산이 모두 끝난 뒤 분해에만 썼다.

- **재현**: 81명은 기존 자동값과 일치했다(최대 1.2e-14). P_16·20·23·37은 기존값에 반사 보정 Po가 들어가 있어 원 ALI FH로 재현되지 않는다. 대칭을 새로 쓰지 않으므로 FH 불확실로 분리하고 집단 통계에서 뺐다. 엑셀 0(Nperp-A 17명, Nperp-Pog 5명)은 결측 의심으로 분리했다.
- **ANB는 FH 기울기와 무관하다**: 수치 민감도 2e-16°/°. 남은 ANB 오차는 A·B·N 위치나 정중면 문제다. B를 고정하고 A를 같은 FH의 통과 후보로 바꾸면 엑셀이 후보 범위 안에 드는 경우가 16/66명, 범위 밖 거리 중앙값은 0.47°다.
- **점 후보만으로는 Pog 오차에 닿지 않는다**: 같은 FH에서 통과 후보 범위가 엑셀을 포함한 경우가 Nperp-A 8/51(거리 중앙값 1.05 mm), Nperp-Pog 1/41(2.32 mm, |오차| 중앙값 2.7 mm)이었다. Pog 후보 선택 규칙을 더 다듬어도 남은 오차 대부분은 줄지 않는다.
- **A·Pog 공통 성분**: 반사 보정 없는 81명 중 엑셀 짝이 있는 61명에서 두 오차의 상관은 0.49였다. 둘 중 하나라도 1 mm를 넘는 52명 중 37명은 부호가 같았다. 환자당 자유도 1인 모델로 RMS가 2.94 mm에서 FH 기울기 모델 1.09 mm, N 앞뒤 이동 모델 1.45 mm로 줄었다(기울기 모델이 나은 경우 40/61). 다만 집단 회귀 기울기는 0.98이고, 기울기만 다를 때 예상값은 1.83이다. 따라서 두 원인을 2개 계측으로는 분리할 수 없다. 집단 수준의 체계적 기울기 편향은 없었다(암시 δ 중앙값 ≈0°).
- **MP-FH로 대조**: MP-FH 오차가 뜻하는 기울기는 Nperp 암시 기울기와 상관 0.49였다. 그런데 이 기울기만큼을 Nperp 오차에서 빼면 MAE가 오히려 늘었다(A 1.80→2.23, Pog 3.37→3.96 mm). 공통 FH 기울기 하나로 세 계측을 설명할 수 없다. MP-FH에는 Go·Me 고유 오차가 따로 있다.
- **Pog 정의의 축 의존성**: 기존 Pog 규칙의 δ 민감도는 ALI Pog를 고정하고 좌표계만 돌린 것과 같았다(정의에 의한 추가분 중앙값 0.03 mm/°, 최대 0.23, 순회전 −2.0 mm/°). 창 경계 선택은 11명(모두 상단)이고 오차가 더 크지 않았다. 20명은 최전방점이 ALI에서 10 mm를 넘어 ALI로 되돌아갔다(MAE 2.83 vs 정상 3.56 mm). 축 각도에 따라 후보 유무가 바뀌는 v2 문제는 새 추적기의 ROI 문제이며, 기존 Pog 계측 규칙의 정의 전환 문제가 아니다.
- 판단: 남은 Nperp 오차의 큰 부분은 환자별 기준(FH 기울기 또는 N 앞뒤 위치) 성분이다. 점 후보 쪽 개선으로는 닿지 않는다. 그렇다고 이를 엑셀로 맞춘 δ로 보정하면 엑셀 맞춤이 되므로 하지 않는다. 테스트 5개 통과. 보고서: [1-2 진단](../Result_py/CBCT/patient_pipeline/v2/develop85/apog_axis_diag_v1/report.html).
