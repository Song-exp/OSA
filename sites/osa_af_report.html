분석 설정과 읽는 법
  • 공식 PSG 리포트를 바탕으로 복원한 전체 AHI와 앙와위 AHI에 각각 자연로그 log(AHI + 1)을 적용했다.
  • 선형회귀 log(AHI + 1) ~ 나이 + 성별 + BMI + 인자 하나를 결과별로 적합했다. n은 해당 회귀에서 필요한 값이 모두 있는 환자 수다. 자동 계측 결측을 엑셀값으로 채우는 대신 각각의 계측 열을 별도 분석했다.
  • 피처 정의 보고서의 A~F를 기준으로 직접 계측값과 해부학적 비율·기하 계산값을 포함했다. G의 PCA·요인·잔차·종합 점수와 혀·구강 공간의 복합비 세 개는 후속 분석 범위다.
  • β는 표준화 계수다. 양수면 인자가 클수록 AHI가 높은 방향이다. 괄호는 β의 95% 신뢰구간이다. p는 인자 계수 검정이고, q는 결과 변수별 전체 A~F 검정에 적용한 Benjamini–Hochberg 보정값이다.
  • ΔR²는 같은 환자에서 나이·성별·BMI만 넣은 식 대비 해당 인자 하나를 추가했을 때의 R² 증가다. 엑셀·자동 버전과 서로 비슷한 지표가 함께 있어, 유의 행 수가 서로 다른 해부학적 신호의 수를 뜻하지는 않는다.
  • 후속 회귀식의 후보를 고르는 탐색 분석이다. 이 표는 표본 밖 예측력과 여러 인자를 함께 넣었을 때의 기여를 평가하지 않는다.
